# ABYSS REACTOR 共通アートディレクション

全素材はこの方針に揃える。生成AIに投げる際は、各プロンプトの冒頭に下の「共通プロンプト」を付ける。

## コンセプト
「重工業製品としての原子炉容器 × 近未来研究施設」。サイバーパンクのネオン街ではなく、**ネジ・鋳物・研磨金属・耐圧ガラス・導光 LED** でできた実在しそうな装置。発光は「装置が動いている証拠」として必要な場所にだけ置く。

## カラー
| 用途 | 色 |
|---|---|
| ベース | 黒 #050607 / ガンメタル #1d2126〜#3a424b / シルバー・クローム |
| 通常時の発光 | シアン #3CDCFF（彩度は控えめ、暗部を多く残す） |
| 警戒・中期待 | 赤 #FF3A3A、琥珀 #FFB030 |
| 高期待 | 赤＋金 #FFC040 |
| 最上位（OVERDRIVE・確定） | 虹（色相が回るグラデーション）＋白い飛び |

通常時は画面の 70% 以上を暗部にする。高期待演出との落差を必ず残すこと。

## 素材感
- 金属：ヘアライン研磨、エッジに細いハイライト、六角ボルト、パーティングライン
- ガラス・樹脂：わずかに青い透過、縁が光る、指紋や汚れは付けない
- LED：導光板越しの柔らかい発光。点の LED を並べただけの見た目は避ける
- 光源：**左上から**で統一。影は右下に落とす

## 形のモチーフ
八角形（機関モジュール）、同心円リング、放熱フィン、制御棒、エネルギーカプセル、アイリス状に開くプレート（深淵コア）

## 文字
英字は幅広の幾何学的なサンセリフ（Orbitron 系）、和文は極太ゴシック。ロゴはクロームの押し出しに、黒い太縁と内側の発光線を入れる。

## 禁止
実在機種・実在メーカーのロゴやキャラクター、既存作品の模倣、絵文字、フラットな Web UI、全面ネオン、紫とピンクのサイバーパンク街並み
