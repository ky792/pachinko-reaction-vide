## 2. 伸びている型（分かったこと）

### 歴史系：悠遊道「名機回顧録」
- **「【一発台 誕生と終焉】33台の名機と振り返るその歴史 名機回顧録#205」→ 約111万回（22分42秒、2024-08）**。[YouTube](https://www.youtube.com/watch?v=QUV9KeB-Kn8)
  - タイトルの型：**【テーマ 誕生と終焉】＋「◯台の名機と振り返る」＋シリーズ名と番号**。
  - 章立て（概要欄の目次）：プロローグ → 始まり → 源流 → 登場 → 全盛期 → **「お上ブチギレ」（規制）** → ポスト◯◯が躍動 → 終焉 → **「◯◯は死んでいなかった」（意外な続き）**。
  - つまり「誕生→全盛→規制→その後→実はまだ生きている」の物語の形。牙狼回・エヴァ回の章立てとほぼ同じで、ナギバクの方向は合っている。
- 同じチャンネルの初期の「パチンコの歴史⑦ 役物機とは？（ゆっくり解説・11分）」は約5千回（2019）。**仕組みの説明だけの回は伸びず、名機をたくさん並べて振り返る回が伸びている**。[YouTube](https://www.youtube.com/watch?v=EC_ALA9daEs)
- ほかに「権利物 誕生と終焉 名機9選」「80年代の羽根モノ11選」など、**ジャンル（仕組み）ごとに名機を並べる回**が続いている。

### ニュース・解説系：オワコンちゃんねる
- 投稿頻度が高い（週3〜4本、決まった時刻）。平均11分。
- 本編を総集編チャンネルに束ねて、もう一度回している。

### ショート
- ホール公式でも、短い「新台の◯◯」ネタのショートで数十万回。長尺の切り抜き・宣伝としてショートを使う価値がある。

## 4. 注意（調べて分かったリスク）
- 2025年7月から、業界の**広告宣伝ガイドライン（第3版）**が強化され、YouTube・SNSのパチンコ・パチスロ動画にも影響していると紹介されている（出玉・設定の示唆、「狙い目」機種の示唆、取材告知など。AIキャラ・生成素材はAI生成の明示）。主な対象はホール・演者・ライター側だが、個人の解説・歴史動画にどこまで及ぶかは未確認。**特定のホールや機種を「打ちに行け」と勧める言い方はしない**。一次資料（業界団体の公表文）で要確認。出典：[むちぼくブログ](https://re.muchiboku.blog/2025/09/15/%E3%80%902025%E5%B9%B47%E6%9C%88%E8%A6%8F%E5%88%B6%E5%BC%B7%E5%8C%96%E3%80%91%E3%83%91%E3%83%81%E3%82%B9%E3%83%AD%E5%8B%95%E7%94%BB%E3%81%AF%E3%81%A9%E3%81%86%E5%A4%89%E3%82%8F%E3%82%8B%EF%BC%9F/)、[PiDEA X](https://www.pidea.jp/articles/1749711532)
