# ナギバク：脚本・音声演技ルール（再利用版）

> 方針の原典は `docs/NAGIBAKU_SCRIPT_VOICE_DIRECTION.md`（2026-10-14）。この文書はそれを **毎回の台本づくりと音声調整で使うチェックリスト** に整理したもの。
> 対象は研究所シリーズ（`lab/`）と反応集（`reaction/`）の両方。映像システム・画面構成・話者IDはこのルールの対象外（変えない）。
> 初出の題材：PR #4 改善版B（65%規制×真・北斗無双）。具体例はそこから取っている。

---

## 0. 作業の順番（毎回これ）
1. 史実を1〜2文ずつに分けて並べる（出典は `SOURCES.md` で確認できるものだけ）。
2. 各史実に「打っていた人が自然に言う一言」を付ける。
3. 必要なところにだけ短いボケ／皮肉を足す。足しても笑えないなら削る。
4. 新旧対照表・面白くなる理由・読みと間のメモを作り、**ユーザーの承認を待つ**。
5. 承認後に音声を作り、AB試聴でセリフ単位に直す。動画は短尺1本だけ出して確認。

---

## 1. 掛け合い（脚本）のルール

### 1-1. 役割
- ナギ＝冷静な標準語、バク＝元気な関西弁。**違いは口調より「何に食いつくか・どう判断するか」で出す**。
  - ナギ：仕組み・時系列・数字の矛盾に気づく。皮肉は乾いた短い一言。
  - バク：打ち手の体感・ホールの景色・店の都合に気づく。驚き・怒りは具体的な状況で言う。
- **「ナギが情報 → バクが感想」の単純交互にしない。** 目安：1パートにつき
  - バクが事実や推理を先に言う行を **1つ以上**
  - ナギがツッコミ・皮肉を言う行を **1つ以上**
  - 同じ人が2行続く箇所は情報の区切りに限る（説明が続くだけなら1行にまとめる）

### 1-2. セリフの作り方
- **1セリフ＝1情報 or 1反応**。ナギ20〜30字、バク10〜25字が目安。読点は2つまで。
- 語彙は「ホールで本当に聞く言葉」：島・隣の台・入れ替え・外す・入る／入らん・回す・ST抜け・突入・ヘソ など。
  - 良い例：「隣に80%おるのに、65%で勝負せえ言うんかい！」（景色が浮かぶ）
- 疑問は短く聞き返す：「え、普通に？」「5月以降だけ？」。視聴者が思う疑問を先に口にする係は、どちらがやってもよい。
- 視聴者に推理させる順番にする：前提 → 疑問 → 事実 → **答えの直前でキャラが気づく**。

### 1-3. 禁止（再利用しない悪例）
| 悪例（旧B版） | なぜダメか | 代わりに |
| --- | --- | --- |
| 「どの台も牙を抜かれたんよ」 | 比喩のための比喩。情報が増えない | 「あったなあ、65%規制。あれはキツかったわ」 |
| 「みんな同じ条件で並ぶんやったら」 | オチ用の前振りが会話として不自然 | 前振りは置かない。疑問をそのまま聞く |
| 「65%の手かせ付けて」 | 意味を一度変換しないと分からない | 「隣に80%おるのに、65%で勝負せえ」 |
| 「あいつ、一番乗りで並んどっただけか」 | 前振りに依存した回収。笑いにならない | 具体的なホール目線の皮肉で落とす |
| 「……はぁ？」「……ほな」 | 語頭の「……」は間を作るだけで会話が止まる | 「え、」「ほな、」と言葉で始める |

- 抽象比喩（牙・手かせ・一番乗り・○○の亡霊 など）を足して「面白くしたこと」にしない。
- オチを言い直さない（「つまり〜ってことだね」を後ろに付けない）。
- 伏線回収は、会話として自然に出てくるときだけ。回収しても笑えないなら伏線ごと削る。
- 参考チャンネルのセリフ・キャラ設定・音声をコピーしない。

### 1-4. オチの型（研究所シリーズ）
1. 事実で状況を作る（ナギ or バク）
2. 打ち手／店の立場で「それっておかしくない？」と気づく（主にバク、叫んでよい）
3. もう一段の事実で皮肉を確定させる、または乾いた一言で落とす（主にナギ、短く）
- 大オチの叫びは1パートに1回。叫びの後に説明を足さない。

### 1-5. 事実の扱い
- 出典で確認できる事実と、キャラの体感・推測を混ぜない。体感はバクの「〜やったわ」「〜やろ」で、推測はナギの「〜だろうね」で示す。
- `SOURCES.md` にない順位・稼働・「一番」は言わない（ken_full では稼働順位を扱っていない）。
- 65%と約80%を「同じ定義の数字」と断定しない（一次資料未確認）。
- 台本の頭に `# 未確認:` コメントで、言い回しが依存している未確認事項を書いておく。

## 2. 音声演技（合成音声）のルール

### 2-1. まずテキストで直す
音声が不自然なら、パラメータより先に **句読点と言葉を直す**。
- VOICEVOX は読点「、」ごとに **約0.35〜0.5秒** 止まる（B版20本の実測。`pauseLengthScale` 1.0）。止まりたくない所に読点を打たない。
- 「……」は読みに影響しない一方、`@dir pre` を大きくする理由として使われがち。**台本テキストに「……」を書かない**。間が要るなら `pre` だけで作る。
- 「。」で区切った2文は、字幕も2枚に分かれる（`split_parts`）。1文で言えるなら1文に。

### 2-2. 間（@dir pre / post）
- 行と行の間 ≒ 前の行の `post` + 0.05秒 + 次の行の `pre`。**語頭の沈黙・pre・post・読点の間が二重三重にならないか足し算して確認する。**
- 目安（固定値ではない。AB試聴で決める）：

| 場面 | pre | post |
| --- | --- | --- |
| 普通の応酬（食い気味） | 0.05〜0.10 | 0 |
| 話題・画面が変わる行 | 0.20〜0.30 | 0 |
| 聞き返し・ツッコミ | 0〜0.05 | 0 |
| 大オチの直前（BGMカットと同時） | 0.30〜0.45 | 0 |
| 大オチの後（笑いを置く） | — | 0.30〜0.50 |

- 「なぜここで止まるか」を一言で説明できない間は入れない。沈黙で笑わせる箇所は1パートに1か所まで。

### 2-3. 1セリフの中の演技（フレーズ単位で設計する）
全体の `speed` / `int` を上げ下げするだけで済ませない。セリフごとに次の4つを決めてメモする。
1. **区切り**：どこで息継ぎするか（＝読点を打つ場所）。
2. **アクセント核**：一番聞かせたい語（数字・機種名・オチの語）を `emph=` に1つだけ。2つ以上は強調にならない。
3. **語尾**：下げて言い切る（事実・皮肉）／上げる（聞き返し・驚き）／伸ばす（呆れ・余韻）。
   - 聞き返しは「？」で上げる。文末を「〜ん？」「〜の？」にすると上がりやすい。
   - 皮肉・言い切りは「。」で終え、`int` を下げて平らに落とす（0.85〜0.95）。
4. **速さの緩急**：前置きは速く、核の語の直前で落とす。1行の中で変えられないときは、行を分けるより「核の語を文末に置く」語順にする。

- ナギの casting には全行に語尾の伸ばし（`drawl.end` 1.25）と読点後の持ち上げがかかる。短い返し（〜10字）は伸びが目立つので、AB試聴で間延びしたら「語尾を言い切る形に書き換える」を先に試す。
- バクの叫び（`バク!:`）は `excited`（別話者ID）に切り替わる。叫びは1パート1回にして、声の切り替えを特別なものにしておく。
- 合成音声らしいクセ（妙に平らな言い切り、急に上がる語尾）は、皮肉や呆れの行では **演技として残してよい**。消すか残すかは、その行の感情に合っているかで決める。

### 2-4. 読みの確認
- 生成後は `voices/_kana.txt` を見る。数字や機種名が `/` で割れていたら `voice/dictionary.json` の `kana_fix` で1語にする（例：65% → ロクジュウゴパ'アセント）。
- 新しい％・機種名・業界用語が出たら、辞書に足してから生成する。
- 読み間違いの検査・修正の手順は `docs/READING_CHECK.md`（声を作る前の `scripts/reading/precheck.py`、作ったあとの Whisper 照合、直した行だけ作り直す `scripts/reading/fix.py`）。字幕と読みを分けたいときは台本に `《表記|よみ》` と書く。

### 2-5. 変えないもの
- 話者ID・casting の基本値（speed / pitch / intonation / drawl）は勝手に変えない。変えたいときは AB用の別ファイルで聞き比べを用意し、ユーザーに選んでもらう。
- 参考動画（Fラン大学就職チャンネル）の抑揚を「再現」と言えるのは、音源を実際に解析できたときだけ。解析できていない場合は「未検証」と書き、必要ならMP4をユーザーに頼む。

## 3. 提出前チェック（人が聞いて判断する項目）
- [ ] パチンコを打つ人が初見で全セリフの意味を分かるか
- [ ] 抽象比喩・「……」・説明の言い直しが残っていないか
- [ ] 説明↔感想の単純交互になっていないか（1-1 の目安を満たすか）
- [ ] 行間の無音を足し算して、意図のない0.5秒超えがないか
- [ ] 各行の核の語・語尾の上げ下げが、意味と感情に合っているか
- [ ] 画面の情報（読む）とセリフ（聞く）が同じことを繰り返していないか
- [ ] 未確認の史実を断定していないか


## 追記（2026-10-18 ユーザー指定）
- 大当り確率をセリフで言うときは小数点を付けない（1/319.7 → 「1/319」）。画面のカードは正式な値のまま。
- 「突確」は「とつかく」と読む（voice/dictionary.json）。

## 追記（2026-10-23 ユーザー指摘：「セリフ回しがずっと不自然。パチンコやる奴がする会話じゃない」「もうちょい俗っぽい会話してええ」）
- **数字を復唱して驚くだけの反応は禁止**。数字を聞いたら、打ち手は財布・ホール・体感の話に持っていく。
  - ✕「7500！？1回で！？」→ ◯「7500て、それ引けたら今日もう帰れるやん」
  - ✕「1777分の1て、もう宝くじやん。」→ ◯「1777とか、ハマったら諭吉何枚溶けんねん」
  - ✕「平日で2万なら、店はにっこりやな。」→ ◯「そら店も釘締めへんわ。いや、締めるか」
  - ✕「見た目は金色やのに、中身は別もんや。」→ ◯「金色の顔して、中身ミドルかい」
- **出典を守るための書き言葉を台詞にしない**。「〜って紹介されてる」「公平に言うと」「ざっくり言うと、そう」→「らしい」「業界誌に載ってた」「〜ってコラムもある」。細かい出典は画面のカードと台本の `#` に回す。
- **ナギも打ち手**。年表を読むナレーターにしない。データ派として、期待値・継続の計算・店の思惑で話す（例：「計算すると、続くのは約65%」「そのぶん、回収も頑張ってたと思うよ」）。
- 俗っぽい語彙はOK：溶ける・単発・スルー・ドル箱・釘締め・ガラガラ・給料日・虚無・オトン など。差別語・人を傷つける言葉は使わない。
- 誇張はしない（「シリーズが終わった」「死んだ」など）。数字で言えることだけを強く言う。
