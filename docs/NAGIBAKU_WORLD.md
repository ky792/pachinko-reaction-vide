# ナギバク研究所：世界観と発明品（設定資料）

> 2026-10-27 制定（ユーザー指示「ナギバクIP化・研究所世界観の導入」）。今後の全シリーズ（歴史回・新台解説・ニュース）の台本と演出はこれに沿う。
> キャラの性格・口調・デザイン・声の設定は変えない（`NAGIBAKU_DIALOGUE_VOICE_RULES.md` が優先）。この資料は「どこで・何を使って解説しているか」を足すもの。

## 1. 舞台
- ナギとバクは **「ナギバク研究所」** に住んでいる。研究所では、パチンコ・パチスロのスペック・歴史・業界ニュースを研究している。
- 動画の基本の舞台は研究所。背景（研究室の大型モニター、左が青＝ナギ側・右が橙＝バク側）、モニターに映す資料、キャラ紹介の肩書きで世界観を出す。
- シリーズごとの見た目（歴史回＝紺のラボ、新台解説＝号外、ニュース）は変えない。**どの見た目でも「研究所から発信している」という前提は共通**。
- 研究所の外（ホール・メーカー）の話は「バクが打ってきた」「ナギが資料を集めた」として持ち込む。

## 3. 発明品のルール
発明品は**解説装置**。ギャグのためだけに出さない。

1. **出す理由を1つに絞る**：その回で一番分かりにくい仕組み（継続率の内訳、振り分けの条件、昔の規制など）を見せるときだけ。全部の回に出さなくていい。
2. **流れは「疑問が出る → バクが起動 → 装置が見せる → ナギが読み解く」**。いきなり起動しない（唐突になる：2026-10-27 ユーザー指摘）。先にスペック表の言葉などに引っかかって「これ、どういう内訳や？」→「あれ起動するか」とつなぐ。起動の一言はバク、結果の説明はナギ。装置自体はしゃべらない（声のキャストを増やさない）。
3. **数字は公式資料で確認したものだけ**。装置が出すのは公式の数字と、そこからの計算（計算は「計算」と明記）。推測の数字を装置に言わせない。
4. **ギャグは軽く1往復まで**：煙が出る・ちょっと暴走する・名前が長い等。テンポと情報量を削らない（目安：発明品のくだりで増える尺は10秒以内）。
5. **使い捨てにしない**：同じ種類の解説には同じ発明品を再登場させる。登場した回は `lab/inventions.json` の `appearances` に追記する。再登場時は「前にも使ったやつ」と分かる一言を入れてよい（説明し直さない）。
6. **他チャンネル・他作品の道具に似せない**（名前・見た目とも）。実在メーカーやホールを下げる使い方をしない（案件を見据えて敵を作らない：2026-10-26 ユーザー方針）。

## 4. 発明品カタログ
正本は `lab/inventions.json`（名前・用途・使う場面・見た目・登場履歴）。新しい発明品を作ったらここに足す。

| No. | 名前 | 何を見せるか | 主な出番 |
|---|---|---|---|
| 01 | **RNC-01**（継続率解析ロボ） | メーカー公表のトータル継続率を、RUSH単体の継続率と時短での引き戻しに分けて見せる | 新台解説（RUSHの章） |
| 02 | スペック透視メガネ | 見落としやすい振り分け・突入条件・小当たり経由など、スペック表の細かい条件 | 新台解説（初当たり・出玉の章） |
| 03 | 時空転送装置 | 過去の台・当時の規制・当時のゲーム性へ「飛ぶ」。章の年代の切り替え | 歴史回（章の頭） |
| 04 | ハマり予報機 | 大当たり確率から「◯回ハマる確率」を計算してレーダーで見せる | 新台解説・確率の比較 |
| 05 | 出玉はかり | 2つの出玉（1500個と3000個、旧台と新台など）を天秤で比べる | 出玉の章 |
| 06 | 振り分けルーレット | 振り分けをルーレットにして、1つずつ止めながら説明（円グラフの動く版） | 初当たり・RUSH中の振り分け |
| 07 | ボーダー電卓 | ボーダーや期待値を電卓で叩き出す | 打ち手目線の章 |
| 08 | 上乗せシミュレーター | 上乗せゾーン（ウバウネ決戦など）を、公表の振り分けどおりの確率で何百〜何千回も回し、分かれ方と平均を見せる（seed固定なので毎回同じ結果） | ラッキートリガー・上乗せの章 |

- 動き：どの発明品も、起動（落ちてくる→震えてスキャン）のあとはずっと動いている（浮く・点滅・回転）。段が出るたびにぴょんと跳ねて反応する。ロボは右腕を上げ、胸のモニターに今の数字、ルーレットは次の項目まで回って止まる、はかりは揺れてから傾く、電卓は数字がパラパラ回ってから止まる。
- 見本：`episodes/invention_demo`（全8種、声なし）
- 上乗せシミュレーターの中身は `"sim": {"buckets": [{"k": "3000個", "p": 50}, …], "values": [3000, …], "trials": 1000, "seed": 7, "run_sec": 4.0}`。`@hl 0` で回し始め、`@hl 1` で確率どおりの割合（黄色の点線）と平均を重ねる。上限が書いていない枠は、その値で止めて計算したと note に書く。乱数のシミュレーションなので、ナギには「確率どおりに近づく」と言わせ、「必ずこうなる」とは言わせない

### RNC-01（継続率解析ロボ）
- 白×黒のバク（獏）型ロボ。背中に青いデータタンク（うさぎのマーク）、電子アイ、足裏ライト。絵は `generator/assets/inventions/rnc01/`（ユーザー提供、2026-10-27）。
- **呼び方：バクは正式名称で「RNC-01（アールエヌシー ゼロワン）」、ナギは長いので「レン」**。
- 表情はエンジンが流れで切り替える：出てくる間は寝てる（すやすや）→ 起動で飛び起きる（びっくり）→ 考え中（首をかしげる）→ 煙のギャグ中は困り顔（ふるえる）→ 結果待ちは疲れ顔（ため息）→ 結果1段目＝分析中 → 段が出た直後＝にっこり（ジャンプ）→ 最後の段＝解説（前のめり）。切り替えの瞬間は0.15秒で重ねて、少しふくらむ。`"faces": ["bunseki", "genki", "kaisetsu"]` で段ごとに指定もできる（ほかに tsukare・bikkuri・nemu）。

### 発明品の場面のタメ（2026-10-28 ユーザー指摘）
- 疑問のあと（0.5秒）、起動のあと（発明品が起きるのを見せる 1.5秒前後）、結果を待つ前（0.5秒）、合計を出す前（0.6秒）と出した後（0.4秒）に `@pause` を入れる。説明のテンポは詰めたまま、発明品の見せ場だけ間を取る。

## 5. 台本での書き方
```
バク: ほな、ウチの発明の出番や。RNC-01、起動！
@show invention:yokai_robot      ← data_patch.json の "invention" に中身。device でカタログの発明品を指定
@hl 0                             ← hold=true のときだけ。1段目をここで出す
ナギ: …（結果の1段目を読む）
@hl 1                             ← 次のセリフの頭で、結果の2段目を出す
ナギ: …
@hl 2
ナギ: …（合計）
@clear                            ← 発明品を片付ける
```
- `@show invention:<キー>` の中身（`data_patch.json` → `"invention": {"<キー>": {...}}`）
  - `device`：`lab/inventions.json` の id（見た目と名札はカタログから出る）
  - `heading`：パネルの見出し（短く）
  - `steps`：結果の段（4段以上なら新しい3段だけ表示。ルーレットは全部が盤面に出る）。`short` はルーレット盤面の短い表記。`{"k": 見出し, "v": 数字, "s": 補足, "c": "nagi"|"baku"|"key"}`。`@hl 1`, `@hl 2` で段を足す
  - `total`：最後の段（任意）。`{"k": ..., "v": ...}`
  - `formula`：計算式の1行（任意）。`note`：出典の1行（必須。公式資料名を書く）
  - `gag`：`"smoke"`（起動時に煙）／`"sparks"`（バチバチ）／`"flash"`（ピカッとまぶしい）／`"none"`
  - `hold`：`true` にすると、1段目も `@hl 0` まで待つ（起動のあとにギャグを挟んで、ナギの「解析結果」に合わせて出すとき）
- 起動の効果音（キュイーン＋ピピッ）と、段が出るときの効果音はエンジンが自動で付ける。

- キャラ紹介の肩書き：ナギ「ナギバク研究所 解析担当」、バク「ナギバク研究所 メカニック（自称エース）」。
- 資料パネルのラベル（`DATA LOG` / `NAGI ANALYSIS`）は「研究所の端末に出ている」体。発明品のパネルは `BAKU WORKS` ラベル。
