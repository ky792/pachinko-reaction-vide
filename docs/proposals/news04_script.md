## 面白くなる理由
- 打ち手が毎回お金を入れている「台の横のユニット」の、見えない後ろ側の話。**店→認証協→製造会社→部品の業者**とお金が流れ、真ん中で上乗せされたとされる仕組みを、図の上で一歩ずつ追う。
- 入口の数字が強い：1億7500万円。バクの「ウチの負けを全部足しても届かへんわ」で打ち手の感覚に落とし、第2章で**台数で割ると1台あたり約7100円**（バク「ウチが1回の負けで溶かす額と変わらんやん」→ナギ「1台ぶんは小さくても、2万台を超えると、億になる」）。
- 2023年の「ユニット不足」の数字（スマート遊技機96万台に対しユニット45万台の見込み）で、認証協が**お金の通り道のど真ん中**にいることを裏づける。
- 大オチは前回の型をあえて繰り返す自己ツッコミ：ナギ「逮捕は、有罪が決まったって意味じゃない」→バク「それ、前の回も言うてたやん！」→ナギ「大事なことは、何回でも言う」。当事者を笑わず、公平さそのものをネタにする。
- 章の終わりの一言：「台の横の小さい機械の後ろで、億のお金が動いてた」（ナギ）。比喩ではなく、報道の額と機械の話。

## 配慮した点
- 実名・年齢・住所は出さない（「元代表理事」だけ）。団体名は全ての報道に出ており、仕組みの説明に要るので出す。
- 逮捕の段階なので「疑い」「〜とみられてる」で言い、本人の認否が報道に無いことと、有罪が決まったわけではないことをナギが明言。
- 動機は推測しない（2023年のユニット不足は「団体の大きさ」の裏づけとしてだけ使い、水増しの理由とは結びつけない）。
- 使い道（不動産・ブランド品など）はテレ朝系のみの報道で、人を晒す方向になるので言わない。
- 店・打ち手への影響は報道に無いので「分かっていない」と言い、「ウチの財布から抜かれたわけやない」とも決めつけない。
- 特定のホールや機種を勧める言い方はしない。画像は使わない（報道写真・人物・実在の機器の写真なし）。図解カードと演出だけ。
