## 長さ
- 184行、推定 **約15分**（声の長さは文字数からの推定）。エヴァ回（39分）の半分くらい。
- エヴァ回並み（30分以上）にするなら、各台の演出・リーチ・口コミを調べて足す（1台あたり4〜6行）。

## ここで面白くなる理由
1. **初代が強すぎてルールが変わる** → 「初代だけ82%のまま打てた」で、規制の話がホール目線になる。
2. **数字の伏線**：OPでナギが「50%・82%の形が、また戻ってくる」と振る → 閃騎鋼（51%・77%）、GOLDSTORM翔（電サポ中82%）、月虹ノ旅人（50%・81%）でバクが毎回気づく → まとめで回収。説明で言い直さない。
3. **顔の役物の進化**：F.O.G.（2010）→ F.F.O.G. → P.F.O.G. → L.F.O.G. → I.F.O.G. → 3D.F.O.G. をバクの「結局ずっと進化しとるな」でつなぐ。
4. **速さの浮き沈み**：RED REQUIEM でスピード感が落ちる → 冴島鋼牙で「待つのがしんどい」 → 真・牙狼で秒速 → 1回転で決着、を章末のヒキでつなぐ。
5. **現代の基準と照らし合わせる**：初代の1/397は「今の1/399とほとんど変わらん」と言う（重いとは言わない）。
