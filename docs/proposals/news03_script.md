## 面白くなる理由
- 打ち手なら誰でも知っている「店の裏の交換所」が、なぜわざわざ別の場所・別の会社なのかを、実際の事件から逆に解く。知ってるつもりの景色の「理由」が分かるのが気持ちいい。
- 入口の引っかかりが強い：**3500円・景品4枚**で書類送検。バクの「景品4枚でもアウトかい！」が、そのまま「金額じゃなくて形の問題（条文に金額の線はない）」の説明につながる。
- 2017年の政府答弁書の「第三者が店と実質的に同じなら違反になりうる」が、今回の「名前は別会社、中身は店」とぴったり重なる。報道 → 条文 → 答弁書の順に、推理のように答えが出る。
- 大オチは公平さで落とす：ナギ「書類送検は、有罪が決まったって意味じゃない」→ バク「最後にめっちゃ真面目なこと言うやん！」（news02 の「夢のない話すな」と同じ型で、事件の当事者を笑わない）。
- 章の終わりの乾いた一言：「あの距離が、法律の上ではいちばん大事な距離」（ナギ）。比喩ではなく、交換所が店の外にある実際の距離の話。

## 掛け合いの組み方（ルールの確認）

## 未確認（台本の `# 未確認:` と同じ）
- 「宮城県の店でこの種の摘発は2007年以来」：khb の本文のみで確認 →「って報じられてる」
- 「店以外の会社が買い取るなら、この条文には当たらない」：法律事務所の解説（mc-law.jp）→「って解説されてる」
- 罰則の上限（拘禁刑・罰金の額）は一次資料で確かめられなかったので、台本では言わない
- 送検の正確な日付・違反が分かった経緯は報道に無いので言わない（報道日 2026年10月30日 で言う）

## 配慮した点
- 実名・店名・会社名は出さない（「宮城県石巻市の店」「経営会社と元社長の男性」まで。年齢も言わない）。
- 書類送検の段階なので「疑い」「〜とみられてる」で言い、まとめで「有罪が決まったわけではない」とナギが明言。
- 動機は報道に無いので推測しない（業界の減収などと結びつけない）。元社長の発言は報道の要約の範囲だけ。
- 客の扱いは報道に無いので言わない（「打つ側の手順は変わらない」「送検されたのは経営会社と元社長」だけ）。
- 特定のホールを勧めたり、換金を勧めたりする言い方はしない。三店方式の合法・違法を断定せず、条文と政府答弁の範囲で話す。
- 画像は使わない（報道写真・店舗写真・実在の景品の画像なし）。図解カードと演出だけ。
