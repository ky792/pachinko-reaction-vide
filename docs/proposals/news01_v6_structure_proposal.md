## 3. 「ここで面白くなる理由」

- **問いがホールでの損得そのもの**：ボーダー・実際の出玉・乗り換えは、新台が入ったときに打ち手が真っ先に調べること。バクが聞くのが自然で、視聴者も知りたい。
- **問1「突入率上がったのに、ボーダー下がらへんのかい！」**：売り文句（シリーズ最高）と、打ち手の物差し（ボーダー）がズレていることが分かる。ナギの「私は打たないから知らない」で、打たない兎の設定も効く。
- **問2「ポップの1500、信じたらあかんやつや」**：1500は払い出し、実際は約1400。パチンカスなら知っている「表記と実際の差」を、バクが自分の言葉で怒る。
- **問3「結局、釘やんけ！」**：レイとの差を打ち手の単位（初当たり68回で1回・毎日1000回転で22日に1回）に直すと、「乗り換えるより、回る方を打て」という実用的な結論になる。問1の「結局、釘か」とつながる。
- **LTなし**：「一撃は期待でけへんな」とパチンカスの言葉で言わせ、昔ながらのST好き向け、という台の性格で着地させる。
