# 妖怪ウォッチ回 v8：継続率分解ロボ（2026-10-27）

研究所の世界観の初回実装（docs/NAGIBAKU_WORLD.md）。RUSH章の継続率メーターを、バクの発明品で見せる形に差し替え。

| | 旧（v7.1） | 新（v8） |
|---|---|---|
| 画面 | 継続率メーター（meter:yokai_meter） | 継続率分解ロボ（invention:yokai_robot）：起動→ANALYZING→74%→22%→80%と式 |
| セリフ | ナギ「RUSHだけの継続は約74%。負けても時短100回が付いて、そこで引き戻せばRUSHに戻る。」<br>ナギ「それ込みで、トータル約80%。」 | バク「ほな、ウチの発明の出番や。継続率分解ロボ、起動！」<br>ナギ「……煙、出てるけど。」<br>バク「いつものことや。ほっといたら止まる。」<br>ナギ「解析結果。RUSHだけで続く確率は、約74%。」<br>ナギ「転落しても、時短100回が付く。ここで引き戻せるのが、約22%。」<br>ナギ「2つを合わせて、トータル約80%。」 |
| 尺 | RUSH章 約40秒 | 約54秒（＋14秒） |

- 数字の根拠：SANKYO公式スペック（※4「RUSH継続率：約74％、コマチャレンジ引き戻し率：約22%の合算」、トータル継続率約80%、コマチャレンジ中の図柄揃い約1/399、時短100回）。式「74%＋（26%×22%）→約80%」は計算（画面に明記）。
- 面白くなる所：バクが自信満々に起動→即煙、の1往復だけ。結果はナギが淡々と読むので、説明の量は前と同じ。
- 読み：「煙」「継続率分解ロボ」はかな渡し。「継続」が照合で「計測」に聞こえたので「続く確率」に言い換え。バクの短い一言は余分な音が付くので一文足した。
