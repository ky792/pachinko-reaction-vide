## 面白くなる理由
- 打ち手なら誰でも見たことがある「店の告知を見て察する」感覚が入口。2026年11月10日に警察庁の担当者がそれを名指しで「分かる人には分かる広告」と言った、という**打ち手の日常と行政の言葉がつながる**ニュース。
- 問い①「なぜ広告は暗号みたいになったのか」の答えが一本の筋：出玉や設定はほのめかせない → はっきり言えないから匂わせる（すり抜け）→ 分かる人だけ集まる。バクの叫び「それ、広告やなくて、合言葉やん！」で山場。
- 問い②「打つ側に何が変わるのか」は、**チェックする側の運用**を図で追う：外の機関が店に来て撮る → 検討会 → 是正要望書 → 1年以内にまた来る → それでもなら「別途の対応」（中身は未公表）。規制の中身だけでなく運用を見せる回は競合に見当たらない。
