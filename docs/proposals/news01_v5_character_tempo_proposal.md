## 1. キャラ設定（ここから固める）

画像（v2）の見た目に合わせて、**「打つ猫」と「打たない兎」** を2人の軸にする。

| | ナギ | バク |
| --- | --- | --- |
| 見た目 | 眠そうな白うさぎ。脳みそのタンクとノートPC | オレンジの猫。ゴーグルにつなぎ、八重歯でウインク |
| 立場 | 研究所の解析担当。**台は打たない**。結果と数字だけ聞く | 研究所の現場担当。**新台は初日に打つ**。シリーズは前作から全部打っている |
| 口調 | 標準語。短く言い切る。だいたい眠い | 関西弁の女の子。一人称「**うち**」（「オレ」はやめる） |
| 知っていること | 確率の計算。打っていないので体感はない | **台の仕組み・前作のスペック・ホールの常識**。聞かれる前に自分で言う |
| よく出る型 | バクの体感を確率に直して冷たく返す | 前作の記憶で新台を読む → ナギが数字で裏を取る or ひっくり返す |

**バクが言ってはいけないこと（v5の反省）**
- 打ち手なら知っていることを**ナギに聞かない**（例：「引き戻しってどんくらいあるん？」「どんな人に向いてる台なん？」）
- 代わりに、**前作との違いに自分で気づく**（例：「Type レイは163回やったのに、REDは161回やん」）

**毎回使える「この2人だけ」のやり取り**
1. **体感 → 確率で片付ける**：バク「前のエヴァで時短3回連続スルーしたで」→ ナギ「3回連続スルーは、だいたい4割。普通。」→ バク「普通なんかい！」
2. **「それ、うちが引くやつや」**：良い数字でも悪い数字でも、バクが自分の未来として受け取る（同じ言い回しの意味がひっくり返る）
3. **猫ネタは事実だけ**：手汗 → 「肉球に汗かいてきたわ」（猫は肉球で汗をかく）。たとえ話ではない
4. **打たないナギ**：OPで「打たない方の、ナギです」、最後に「私は打たない。結果だけ聞く」

キャラ紹介カード（`data_patch.json` の intro）の案：
- ナギ：「数字しか信じない。」「台は打たない。だいたい眠い。」
- バク：「関西弁の猫の女の子。」「新台は初日に打つ。」

## 6. 読みと間のメモ
