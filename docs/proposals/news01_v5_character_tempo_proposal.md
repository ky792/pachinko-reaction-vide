## 1. キャラ設定（ここから固める）

画像（v2）から読み取れる見た目に合わせて、**「打つ猫」と「打たない兎」** を2人の軸にする。

| | ナギ | バク |
| --- | --- | --- |
| 見た目 | 眠そうな白うさぎ。脳みそのタンクとノートPC | オレンジの猫。ゴーグルにつなぎ、八重歯でウインク |
| 立場 | 研究所の解析担当。**台は打たない**。結果と数字だけ聞く | 研究所の現場担当。**新台は初日に打つ** |
| 口調 | 標準語。短く言い切る。だいたい眠い | 関西弁の女の子。一人称「**うち**」（「オレ」はやめる） |
| 食いつく所 | 確率・数字の矛盾 | 自分の実戦の記憶・ホールの景色 |
| よく出る型 | バクの体験を確率に直して冷たく返す | 自分の不運を持ち出して、ナギに数字で片付けられる |

**毎回使える「この2人だけ」のやり取り（今回の台本に入れたもの）**
1. **体験 → 確率で片付ける**：バク「前のエヴァで時短3回連続スルーしたで」→ ナギ「3回連続は約4割。普通」→ バク「普通なんかい！」
2. **「それ、うちが引くやつや」**：良い数字でも悪い数字でも、バクが自分の未来として受け取る（同じ言い回しの意味がひっくり返るのが笑いどころ）
3. **猫ネタは事実だけ**：手汗 → 「肉球に汗かいてきたわ」（猫は肉球で汗をかく）。比喩ではなく体の話なので、ルールの「抽象比喩禁止」に当たらない
4. **打たないナギ**：OPで「打たない方の、ナギです」、最後に「私は打たない。結果だけ聞く」。回をまたいで使える締め

キャラ紹介カード（`data_patch.json` の intro）も合わせて変える案：
- ナギ：「数字しか信じない。」「台は打たない。だいたい眠い。」
- バク：「関西弁の猫の女の子。」「新台は初日に打つ。」

## 4. テンポを速くする案

今のv4は約4分32秒。テンポを落としている原因は3つ。

| 原因 | 今 | 案 |
| --- | --- | --- |
| セリフとセリフの間 | 毎回0.40秒 | **0.22秒**（エピソードごとに `episode.json` で決められるようにする。ほかの回は今のまま） |
| ナギの読む速さ | AivisSpeech speed 0.86（気だるさのため遅め） | **0.95**（抑揚0.65と−1.5半音はそのまま。気だるさは言い方と短さで残す） |
| バクの読む速さ | Irodori は Fenrir より約3割ゆっくり | Irodori の `--duration-scale 0.88` で作る（後から早回ししないので音は崩れない） |

- 台本を53→45行に減らした分と合わせて、**約3分30秒前後**の見込み（読みの速さは作ってみないと確定しない）。
- 4分を切るが、中身（数字・図解）は削っていない。もっと尺が欲しければ、次回以降のネタで足す。
- 画面の切り替え（`@show`）の位置は変えないので、図解が出ている時間はそのぶん短くなる。

## 5. 読みと間のメモ

- バクの演技指示（Irodori の caption）は今の「元気でノリのいい、関西弁の女の子〜」のまま。叫ぶ行（「普通なんかい！」「うちやん！」「23人に1人！」）だけ、行ごとに「勢いよく大げさに」を足す。
- 「それもうちが引くやつやん。」は1つ前の行より**低く・小さく**（あきらめ）。caption に「がっかりして」を足す。
- 「合ってる。珍しく。」は2文の間を詰める（0.2秒以下）。「珍しく」は投げやりに。
- 「普通。」「ミドルだから。」はナギの決め台詞。前の間を0.1秒だけ空ける（`@dir pre=0.1`）。
- 「肉球に汗かいてきたわ」の読みは「にくきゅう」。辞書の確認が要る（読み間違えたら `voice/dictionary.json` に追加）。
