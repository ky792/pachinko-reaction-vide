## 4. 声の演出メモ（新しい声用）
**ナギ（AivisSpeech コハク「ねむたい」）**
- AivisSpeech は言葉で演技を指示できない。できるのは速さ・抑揚の強さと、句読点・言葉選びだけ
- そのため気怠さは**台本の書き方**で出す：体言止め、「〜し。」「〜ってやつ。」、助詞を抜く
- 読点は息継ぎの位置にだけ。長い行はゆっくり読まれて間延びするので、1行15字前後まで
- `@dir` の `tail` / `emph` は VOICEVOX 用の仕組みなので、AivisSpeech では効かない（台本には残すが、ナギの音声には反映されない）

**バク（Gemini Zephyr）**
- 1章＝1リクエストで作る。行ごとの演技（`mood` / `tail` / 叫び）は、行番号つきで演技の指示に入れる（`scripts/voice_ab/gemini_dialogue.py` と同じ方式）
- 9・13・19・21行目は「全力で」「叫ぶように」、2・15行目は「軽く流す」
