# 牙狼回 v3：栄光・転落・復活（2026-10-23）

サムネイルのコンセプト「牙狼 栄光・転落・復活」に、動画全体の物語を合わせて組み直した。画面構成・映像エンジン・キャラ・声の設定は変えていない。

## 3. 面白くなる理由（足した掛け合い）
- 「宣伝は、隣の人がしてくれる。」：初代が広がった理由を、ホールの景色（隣が止まらない）で言う。比喩ではなく、そのままの状況。
- 「ないものは、ないと言う。」：数字が見つからない台を正直に言う研究所らしさ。バクの「研究所やのに、データないんかい」と対になる。
- 「6週！？夏休みより短いやん！」→「未来への咆哮は216週」→「比べる相手が悪いわ！」：エヴァ回を見た人に効く比較。数字が主役。
- 「全部入りでも、8週かい！」：GOLD IMPACT で「形も速さも」揃えた直後に落とす。前の行の「これは勝ったやろ」が前振り。
- 「その宝くじが、当たった。」：1/1777を宝くじと言ったバクに、ナギが乾いた一言で返す（台の当たり＝ヒットの二重の意味）。
- 「仕事帰りに9万5千て！どんな帰り道やねん！」：店長の「仕事帰りでも打たれる」とコンプリートの数字をぶつける。
- まとめの「どっちでもなかった。7500個。」「18年見て、答えが出玉かい！」：OPから続いた「速さか、形か」をひっくり返す。

## 4. 読みと間のメモ
- 「未来への咆哮」は辞書どおり「あすへのほうこう」。
- 「1777分の1」「1/400」は辞書の分数ルールで「〜ぶんのいち」。
- 「100万5000円」「9万5千発」「2万5000アウト」は数字のまま。読みは CI の kana と Whisper 照合で確かめる。
- 新しいヒキ（栄光の前半の終わり／6週／8週／スマパチ／牙狼12の稼働）は既存と同じ `pre=0.35 hiki=2〜3`。
- 「宣伝は、隣の人がしてくれる。」「その宝くじが、当たった。」「比べる相手が悪いわ！」のあとは `post=0.3〜0.4` で笑いを置く。
