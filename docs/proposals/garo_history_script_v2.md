## 面白くなる理由
1. **見る理由が最初に来る。** OPで「初代は強すぎて作れなくなった」「中古で100万」を先に出し、本編で回収する（金色になれの章で「最初に言った中古の話、これ」）。
2. **2人の勝負がずっと続く。** 年表の事実がそのまま得点になる。
   - 初代の規制 → 「止められたのは速さじゃなくて形」（ナギ＋1）
   - RED REQUIEM・冴島鋼牙の遅さ → 「遅いと文句が出る」（バク＋1）
   - 魔戒ノ花の最速F.O.G. → 「そこは速さの勝ちでいい」（バク＋1）
   - 月虹ノ旅人の50%・81% → 「今のは形の勝ちや」（ナギ＋1）
   - GOLD IMPACT → 「どっちも取りにきとるやん。欲張りやな、サンセイ」
   - まとめ → 「引き分け」「18年見て引き分けかい！」
3. **数字の前に体験を置く。** FINALは「台が揺れる→隣の人のほうがビクッと→驚かせたのあなたの台→で、外れた」から入って、数字は最後に1行。
4. **ナギが情報、バクが感想の交互をやめた。** バクが先に事実を言う行（FINALの震撃、真・牙狼の「これや！」）と、ナギが短く刺す行（「驚かせたの、あなたの台だけどね」「引き分け」）を増やした。
