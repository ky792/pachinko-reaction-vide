## 1. ねらい
- **ニュース**：2026年10月19日導入予定の「P 新世紀エヴァンゲリオン -319 RED-」（継続約81%・ALL約1,500個・ST突入約75%）
- **フック**：「この台、10年前なら作れなかった」
- **解説**：65%規制（2016〜2019）→ 当時の工夫（シンフォギアの引き戻し込み約80%）→ 規制の撤廃 → 1,500個はP機の上限 → エヴァ15と同じ「王道スペック」→ 今回変わったのは突入率
- **オチ**：継続率も出玉もルールの上限いっぱい。残る勝負は「入りやすさ」。ナギは「様子見で」と気怠げに締める
