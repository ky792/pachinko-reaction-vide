## 1. 構成
1. **ニュース**：エヴァの新作が10月19日に導入。ウリは「ST突入率約75%」（シリーズ最高と紹介）
2. **初当たりの流れ**：直撃約65%＋時短100回の引き戻し → 合わせて約75%。初当たりはほぼ300個
3. **STの強さ**：161回・1/98.9・継続約81%・全部1,500個 → 計算上、STに入ると平均4回ちょっと当たる
4. **前作との違い**：エヴァ15もST中は同じ強さ。変わったのは入り口
5. **打ち手目線**：初当たり1/319.7は重いまま → 締め
