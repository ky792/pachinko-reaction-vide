# ナギバク：脚本・音声演技の制作方針（2026-10-14）
> Claude Codeへの引き継ぎ用。技術基盤の改修指示ではない。ユーザーが明確に評価した／問題視した内容を優先する。

## 1. 今回の結論
- **画面構成・素材情報量・映像システムは現状維持**。2026-10-13に確認した `ken_test90_B.mp4` は、情報を絞り、資料と会話を分けた見せ方が良い。画面を華美にしたり再構築したりしない。
- **掛け合いの軽快さ・言葉選びは「パチンコ・パチスロ オワコンちゃんねる」が参照軸**。普通のパチンコ好き同士が自然に会話するテンポ、短い応酬、共感できる皮肉、無駄のない切り返しを研究する。
- **人工／合成音声のアクセント・イントネーション・語尾・音節内の緩急は「Fラン大学就職チャンネル」が参照軸**。合成音声の不自然さを単にゼロにするより、狙ったアクセントや独特の抑揚を演技として生かす。ただし実際の音源なしに細かい再現データを発明しない。
- **ボケ・ツッコミの役割固定をしない**。ナギは冷静な標準語、バクは元気で関西弁を使う。情報はナギ、リアクションはバク、という交互読み上げにしない。2人とも情報・ツッコミ・提案ができる。
- Fラン側の「巧妙な伏線回収」を目的化しない。笑えない比喩や意味不明な回収より、史実の面白さに自然な一言が添わるほうがよい。

## 2. 明確に不評だった表現（再利用禁止の悪例）
旧B版の
- 「どの台も牙を抜かれたんよ」
- 「みんな同じ条件で並ぶんやったら」
- 「65%の手かせ付けて」
- 「あいつ、一番乗りで並んどっただけか」
は、比喩を使うための比喩になっていて意味が伝わりにくい。前振りを仕込んでもオチが弱い。**こういう抽象比喩を足して面白くしたことにしない。**
「……」を重ね、後から 0.55〜0.80秒などの間を追加して会話を止める設計も要修正。語頭の沈黙と `pre/post` と無音演出が重複していないか確かめる。

## 3. 台本の品質ルール
- まず説明上必要な史実を1〜2文で整理。その情報に対して自然な反応を置く。必要なところだけ短いボケを足す。
- 本当に打っていた／パチンコを知っている人が口にしそうな語彙を使う。「隣に北斗無双おるんやで」のような具体的なホール目線を優先。
- ひとつのセリフでひとつの情報・反応。冗長な説明やセルフ解説は短縮。
- ナギ／バクのキャラ性は **言い回しより判断・興味・価値観** で出す。
- オチを説明し直さない。伏線は自然に入るときだけ使い、笑いのない回収は削除。
- 歴史・規制・継続率などの事実は出典確認と脚本上の推測を分ける。65%と約80%を単純な同定義の数値として断定する説明は保留（一次資料未確認）。
- 参考チャンネルのセリフ・固有キャラ設定・音声そのものをコピーしない。

## 4. 合成音声のディレクション
- 再生スピード・全体のintonationScaleだけを増減して済ませず、語句の区切り、アクセント核、語尾の落とし／上げ、短い母音伸長、短いアクセント強調を **発話・フレーズ単位で設計する**。
- 間は「なぜここで止まるか」が明確なときだけ。通常応酬は詰め、沈黙で笑わせる箇所だけ必要最小限の実時間で検証する。固定秒数を正解としない。
- 既存TTS設定・話者IDは勝手に変更しない。改善には音声のAB試聴を使う。音声が不自然なら、まずテキストの句読点／言葉選びを見直す。
- Fラン参考動画の音源をClaude Code環境で確認できる場合のみ、タイムコードごとに具体的な音節・抑揚・間を測定・記述する。見られない場合は「未検証」と明記し、必要なMP4をユーザーに依頼する。

## 5. 今回Claude Codeに実施してほしい順番
1. 現状の `feat/test90-dialogue` / PR #4 の **B版のセリフ20本**を読み、伝わりにくい言い回しと不自然な「間」を指摘する（参考: `episodes/ken_test90_B/script/01_65hokuto.txt`）。
2. **画面・資料量・レイアウト・映像エンジンに触れず**、65%規制×北斗無双の約80〜90秒を自然な掛け合いへ書き直す。少なくとも終盤の比喩オチを「なぜ規制後の主役が規制前の台だったのか」という具体的なホール目線の皮肉に直す。
3. 生成前に、新旧セリフ対照表と「ここで面白くなる理由」、読みと間の演出メモを提示。**ここで一度ユーザーの承認を待つ**。
4. 承認後、既存の音声・映像フローで **修正版Bを1本だけ短尺出力**。必要ならセリフ単位でアクセント／発話間隔を修正し、再出力。
5. 納品は音声付きMP4のリンク、全台本、差分の説明、制作時間、未確認の史実を簡潔に示す。新たな大規模リファクタ・無関係な監査・PR #3/#4の無断マージはしない。

## 6. 品質チェック（人間が聞いて判断）
- 普通のパチンコ談義としてセリフの意味が初見で分かるか。
- 不自然な比喩・不必要な「……」・間延びで笑いを止めていないか。
- ナギとバクの応酬が軽快で、説明↔感想の単純交互になっていないか。
- アクセント・語尾・間が言葉の意味と感情に合っているか。
- 視聴者が読む情報と、耳で聞く会話の役割分担を壊していないか。
