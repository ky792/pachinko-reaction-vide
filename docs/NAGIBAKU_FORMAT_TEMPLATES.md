# ナギバク：動画の型（2026-10-17 ユーザー指定）

> 新台・ニュース解説は「パチンコ・パチスロ オワコンちゃんねる」型、歴史系は「テイコウペンギン」型。
> ユーザー提供の画面録画（各30〜50秒）から、場面の切り替わりを測って整理した。参考にするのは**構成と見せ方だけ**で、
> 向こうのセリフ・キャラ設定・ロゴ・ジングル・絵柄は使わない。

---

## A. 新台・ニュース解説型（オワコンちゃんねる型）

### 見本の実測
| 時間 | 画面 | 中身 |
| --- | --- | --- |
| 0〜1.9秒 | キャラ紹介1（全面の大きなイラスト＋名前・年齢・肩書き・ひとことプロフィール） | 先輩 |
| 1.9〜4.5秒 | キャラ紹介2（同じ形） | 後輩 |
| 4.5〜9.7秒 | チャンネルロゴ | — |
| 9.7秒〜 | 背景写真の中央に**今日のテーマの図解カード**（出しっぱなし）、下の左右にキャラ（小）、下に2行字幕 | あいさつ → ニュース（何が出る）→ なぜ今か（話題になっている）→ **今日の問い2つ** → やり方（公表情報をもとに解説） |

### ナギバクでの組み方
1. **キャラ紹介**（各約2秒）：ナギ／バクの全身＋名前＋肩書き＋ひとことプロフィール（毎回同じでよい。回ごとに一言だけ変えるのもあり）
2. **番組ロゴ**（約4秒）：「ナギとバクのパチンコニュース」＋ジングル
3. **本題の入り**（約20秒）：テーマカード（機種のスペックカードなど）を出したまま
   - バク：あいさつ
   - バク：ニュース（何が・いつ）
   - ナギ：なぜ話題か（1文）
   - バク：今日の問い（2つ）
   - ナギ：やり方（公表されているスペックをもとに数字で見る）
4. 本編 → まとめ → ED

## B. 歴史系（テイコウペンギン型）

### 見本の実測
| 時間 | 画面 | 中身 |
| --- | --- | --- |
| 0〜約38秒 | キャラの寸劇（2〜5秒ごとにカット・表情が変わる） | 日常の小芝居から、今回のテーマに自然につながる一言で終わる |
| 約38〜44秒 | 登場キャラの名前つき紹介を素早く | — |
| 約44〜47秒 | 番組ロゴ → 今回のタイトル（【〇〇】〜なのか？の問い形） | — |

### ナギバクでの組み方
1. **寸劇**（30秒前後）：研究所での小芝居（例：バクが昔の台の話をする → ナギが「それ、規制のせいだよ」→ 今回の問いへ）
2. **キャラ紹介**（素早く）→ **番組ロゴ** → **問い形のタイトル**（例：【65%規制】なぜ北斗無双だけ80%で打てたのか？）
3. 本編（研究所シリーズの章立て）→ まとめ → ED

## 作るのに必要な画面部品（未実装）
- キャラ紹介カード（全面の立ち絵＋名前・肩書き・プロフィール）
- 番組ロゴカード（ニュース用・歴史用）
- 寸劇用の表情差分（今のv2素材は通常の1枚ずつしかない → 表情を増やすならユーザーに素材を用意してもらう）

## 実装済みの部品
- キャラ紹介カード：`@intro nagi` / `@intro baku`（data の intro）
- **寸劇モード**（2026-10-17）：台本で `@skit on` 〜 `@skit off`。キャラを大きく向かい合わせに出し、左右から登場、話している方が弾む。行ごとに `@dir act=` で動きを付ける（hop / jump / shake / tilt＋？ / shock＋！ / sweat / slump / lean / none）。指定がなければ「！」で終わる行は跳ねる、「？」で終わる行は首をかしげる。実装は `lab/skit.py`
