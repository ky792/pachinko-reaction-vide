## 進め方（全部共通）

1. **ChatGPT に公式の表情集を添付**して、下のプロンプトを貼る。
   - ナギ：`generator/assets/characters/v2/sheets/nagi_faces.png`（ナギ表情集8種）
   - バク：`generator/assets/characters/v2/sheets/baku_faces.png`（バク表情集8種）
2. まず **マスター（N-01・B-01）** を作る。デザインが公式と合っているかを確認してから次へ。
3. 残りは **できたマスターを添付して「ここだけ変えて」と編集**してもらう（N-02〜・B-02〜）。
   - 口・目は「パーツだけの画像」ではなく「そこだけ変えた全身画像」でください。こちらで差分を取って切り出し、位置を合わせます。
   - 少し位置がずれても、こちらで自動で合わせます。ずれが大きい・顔つきが変わったものは使わずにお知らせします。
4. 受け取り方：チャットに添付、または `assets/_inbox/` に下のファイル名で置いてください（どちらでも可）。
5. **背景は透過 PNG**。ChatGPT で透過にならなかった場合は、**真っ白でもグリーン（#00FF00）一色でも**大丈夫です（こちらで抜きます）。
6. サイズは ChatGPT の縦長（1024×1536）で十分です。こちらでアニメ絵用の拡大処理（描き直しではなく画質を保った拡大）をかけて使います。

### 素材発注：N-01 ナギ・正面マスター（通常・無表情）
- **使用目的**：ナギのパーツ式リグの元になる基準画像。試作のすべての場面で使う。
- **具体的な仕様**：

  - 目は閉じたまま、口は小さな「へ」の字で閉じる
  - **立ち耳と頭の間・腕と顔の間にすき間がある**ほうがパーツ分けしやすい（重ならない範囲で公式どおりに）
  - 背景透過 PNG、1024×1536、汗・記号・効果線なし
- **優先順位**：必須
- **既存素材で代用可能か**：✕（今の切り出しは約320px で、寄りのカメラに耐えない。パーツ分けの元にもできない）
- **ファイル名**：`nagi_front_master.png`
- **画像生成用プロンプト**（共通の前置きのあとに）：
```
添付の表情集の「① 通常・無表情」のナギを、1枚の大きなキャラクター画像として描き直してください。
・姿勢と表情は①と同じ：正面寄り、上半身からひざ上まで、両手で青いタブレット（白いうさぎマーク）を胸の前で持つ
・目は閉じたままの眠り目（絶対に開けない）、口は小さな「へ」の字で閉じる
・耳は2本：1本はまっすぐ上に立ち（内側が青）、もう1本は前に折れて垂れていて、折れた部分に黒いデバイス（水色の画面）が付いている。①と同じ側に同じ形で

・紺〜黒のテック系ジャケットとハーネス、胸元に水色の宝石
```
