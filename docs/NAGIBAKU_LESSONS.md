# ナギバク：修正履歴と判断基準（企画・台本・監査の前に読む）

> 使い方は `docs/NAGIBAKU_REVIEW.md` の 4。ここには **ユーザーが実際に指摘したこと** と、そこから引き出した原則だけを「ユーザーの指摘」に書く。
> AIの推測や監査で見つけただけのものは「監査で見つけた候補」に分ける（ユーザーの好みとして扱わない）。

## 原則（ユーザーの指摘から）
1. **ホールの設備と打ち手の動きは、今のホールで実際にどうなっているかから書く。** もっともらしい「不便さ」「便利さ」を想像で作らない。お金の出し入れ・設備・遊び方が出てくる行は、監査Aで必ず確かめる。（指摘1）
2. **「整理できる疑問」と「視聴者が知りたい疑問」は別。** 資料から問いを作ったら、打っている人がそれを気にしているかを企画審査1・5で確かめる。タイトルは口に出して気持ちいい言葉にする。（指摘2）
3. 打ち手らしい会話にする（俗っぽくてよい）。数字の復唱だけで驚かない、書き言葉の出典説明を台詞にしない、ナギも打ち手。→ 詳細は `NAGIBAKU_DIALOGUE_VOICE_RULES.md` の追記（2026-10-23）
4. 抽象比喩・前振り依存のオチで「面白くしたこと」にしない。→ `NAGIBAKU_SCRIPT_VOICE_DIRECTION.md` の 2
5. **お金・決済・換金の言葉は正確に。** 章をキャラの教訓で締めない。（指摘3）

## ユーザーの指摘
### 指摘1（2026-11-05）キャッシュレス回「両替機に並ばなくて済む」
- 起きたこと：キャッシュレス化の利点として、バクに「両替機に並ばんでよくなる」と言わせた（概要とまとめの2か所）。
- なぜダメか：今のホールではお金は台の横のサンドに直接入れるのが普通で、両替機に並ぶ場面は打ち手の実感にない。設備と行動を理解しないまま、それらしいセリフを作っていた。
- 再発防止：原則1。「便利になる／不便」を言わせる前に、その場面で打ち手が実際に何をしているかを一文で書けるか確かめる。書けなければ要確認にする。

### 指摘2（2026-11-05）エヴァ回の企画「継続率はなぜ上がって下がってまた上がったのか」
- 起きたこと：継続率の上下をテーマ・タイトルにした。
- なぜダメか：分析は成り立つが、視聴者がそれを知りたいとは限らない。言葉の響きも悪い。
- 代案の例：「エヴァシリーズの迷走と復活」（これも史実と関心を確かめてから出す）。
- 再発防止：原則2。

### 指摘3（2026-11-05）news02 監査の修正をユーザーが了承（「いいんじゃない」）
- 起きたこと：AIの監査で、デビットを「先払い」と言っていた／「借りてすぐ流したら現金」と交換率を抜かしていた／章の締めをキャラの教訓（「道具は使い方しだい」「店も業界も締めとかなあかん」）で終えていた、を見つけて直し、ユーザーが修正版を了承。
- 再発防止：決済・換金の言葉は正確に（前払い／即時払い／後払い、等価／非等価）。換金が絡む行は交換率を意識する。章は教訓で締めず、打ち手の一言か次の振りで終える。

### 指摘4（2026-11-05）バクの「先輩らしさ」が足りない（追い追い対応）
- ユーザーの言葉：「バクのオワコンちゃんねるの先輩らしさがまだ足りんな。まぁそこは追い追いか」（キャッシュレス回を見て）
- まだ決まっていないこと：どの点が「先輩らしい」のか（例：話を引っ張る・経験からの断言・後輩へのいじり など）はユーザー未確認。推測で原則にしない。次に台本を作る前にユーザーに確かめ、決まったらここに原則として書く。
- 注意：参考にするのは立ち位置と会話の運び方だけ。向こうのセリフ・キャラ設定はコピーしない（CLAUDE.md）。
