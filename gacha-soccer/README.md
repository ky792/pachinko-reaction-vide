# ガチャサッカー（仮） ブラウザ版プロトタイプ

ガチャで引いたランダムな11人を、戦術と局面判断で勝利に導くサッカー×ガチャ×戦術シミュレーション。
React + TypeScript + Vite。バックエンド・外部API・課金・広告・オンライン機能なし。セーブは localStorage。

このリポジトリの他のプロジェクト（動画生成・sns-studio）とは独立しています。`gacha-soccer/` の中だけで完結します。

## 起動

```bash
cd gacha-soccer
npm install
npm run dev        # 開発サーバ（表示されたURLをスマホ/PCで開く）
npm run build      # 型チェック + 本番ビルド（dist/）
npm run preview    # ビルド結果をローカル配信
npm test           # ユニットテスト（vitest）
npm run sim        # バランス検証シミュレーション（npm run sim -- 400 で試合数指定）
```

## 1プレイの流れ

1. タイトル →「新しいチームを作る」で11人をガチャ（GK/CB×2/SB×2/DM/CM/AM/WG×2/ST の本職構成を保証）
2. カードをタップ → 詳細・引き直し（チーム合計5回、同じ本職ポジションで再抽選するのでチームは必ず成立）
3. 運命のスカウト券を持っていれば使用（入れ替える選手＝ポジションを選ぶ → 神選手を確定獲得）
4. 戦術設定（フォーメーション、攻撃方向／守備ライン／プレス／テンポ、2人タップで配置入れ替え）
5. 対戦相手（★1〜★4 の通常5チーム＋裏ボス THE ELEVEN）とモード（監督／選手／フルオート）を選ぶ
6. 試合：オートで進行し、重要局面で一時停止してコマンド選択
7. 結果：スコア・得点者・采配の振り返り（判断の質と結果を分けて表示）・実績
8. 同じチームで次の試合 or 周回終了して新チーム

## 実装状況

### 第1段階：遊べる最小版 — 実装済み
- 11人ガチャ、5回の引き直し、ポジション保証
- 戦術選択（3フォーメーション×4項目）と配置入れ替え
- 2Dピッチ（Canvas）でのオート進行、重要局面でのコマンド選択、勝敗結果
- 効果音（Web Audio でその場で合成。外部素材なし）

### 第2段階：快感の強化 — 実装済み
- 特殊技能 17種（ガチャで出るのは15種。うち2種は裏ボス専用）。弱点・マイナス技能あり
- コマンド進化 5種：高速シザース／キラーパス／ファントムカットイン／天空ヘッド／鉄壁スライディング
- 技能発動・進化のカットイン、ゴール演出（逆転・終盤の勝ち越し/同点・ハットトリックは派手な演出）、決勝点の表示
- ガチャ演出：通常は短くテンポよく、SSR・珍しい技能のみ間とSE、GOD ELEVEN は専用演出（暗転→重低音→タイトル→11枚変化、スキップ可）
- 判断フィードバック：期待値ベースで「好判断／妥当／疑問」を評価し、成否とは別に表示（例：「好判断／判断は正しかった、結果は不運」「疑問の残る判断／結果オーライ」）
- ミュート・音量・演出短縮・再生速度（x1/x2/x4）・「次の局面まで」早送り・演出タップスキップ

### 第3段階：周回の完成 — 実装済み
- 運命のスカウト券：1ドロー（=選手1人の生成）ごとに 1/500、1000回で天井確定、獲得時に天井リセット。天井カウントだけはプレイをまたいで保存
- GOD ELEVEN：1ドローごとに 1/8192（天井なし）。発生したプレイは11人全員が神選手に（本職は維持、能力配分・技能は個体差あり）。以降の引き直しも神選手
- 裏ボス THE ELEVEN（長所と攻略可能な弱点つき。挑戦は任意）
- 戦績・対戦成績・実績12種の保存
- デバッグ機能（設定 → 開発者向け）：両アイテムの確率変更、次ドローで強制発生、天井カウント編集、シード固定、セーブ削除

### 未実装・簡略化している点（正直に明記）
- **選手交代・負傷・カード・ファウル・セットプレー（CK/FK/PK）・オフサイドは無し**。試合は「攻撃の組み立て→局面→コマンド」の抽象モデル
- **ピッチ上の選手の動きは演出用の簡易配置**（フォーメーション基準位置をボール位置に応じてずらしているだけ）。判定は局面モデルで行っており、画面上の座標は判定に使っていない
- 試合中の作戦変更はできるが、フォーメーション変更・配置換えは試合前のみ
- 選手モードでは「指定選手がボール保持者・対応する守備者の局面」のみ介入（受け手としての判断は無し）
- 現在のチームはブラウザを閉じると消える（周回中データは保存しない仕様。保存されるのは天井・戦績・実績・設定のみ）
- 効果音は合成の簡易SEでBGMは無し。顔アイコンは手続き生成の簡易SVG
- 体感確率の調整は未実施（表示成功率＝内部判定の成功率で一致させている）

```
  data/commands.ts   コマンドと進化の定義（表示名・説明・ボーナス）
  data/formations.ts フォーメーション（スロット座標・役割）とポジション適性
  data/tactics.ts    戦術ごとの「局面の起きやすさ」パラメータ
  data/opponents.ts  敵チーム定義（IDから決定的に生成）
  gacha.ts           選手生成・レアリティ・スカウト券/GOD抽選・天井
  run.ts             1周回の状態（引き直し・スカウト券使用）
  team.ts            役割別評価・自動配置・チーム評価
  match/engine.ts    試合シミュレーション（局面生成・選択肢と成功率・期待値・解決）
  match/eff.ts       技能・適性・スタミナ込みの実効能力

tests/core.test.ts      再現性・ポジション保証・天井・GOD・戦術による局面分布・進化条件など
```

### 試合モデルの要点
- 攻撃の組み立て：自チームのパス/判断力 vs 相手のプレス（守備・スピード・スタミナ）で敵陣侵入を判定。相手のプレスやラインで「ショートカウンター」「プレスを剥がしてカウンター」「ライン裏のスペース」の局面が発生
- 侵入後の局面は戦術で変わる：サイド攻撃→サイド1対1（DFの向き＝中切り/縦切りあり）、中央→バイタルエリア、バランス→相手の弱い方
- 各コマンドは「成功率」「成功時の展開」「失敗時の展開（ボールロストの危険度）」が別々。期待値は次の局面まで先読みして計算し、AIの判断と「判断の質」評価に使う
- 例：DFが縦を切っているならカットイン有利、中を切っているなら縦突破有利。相手が高いラインならスルーパス+14%、低いラインならスルーパス-10%・ミドルシュートが有利、など
- スタミナ：プレス積極的・テンポ速いと消耗、遅いテンポは相手を走らせる。スタミナ低下で全能力が落ちる

### 裏ボス THE ELEVEN
- 長所：全能力が規格外、中央突破とスルーパス、猛烈なプレス、神セーブGK
- 弱点：超ハイラインの裏、空中戦に弱いCB、技能「短期決戦」により**スタミナが半分を切ると全能力が大きく落ちる**（終盤に崩壊）

## バランス検証の結果（`npm run sim -- 150`、要点のみ）

| 組み合わせ | 勝率 |
|---|---|
| 通常チーム（引き直し無し）vs ★1 ひだまり | 約70〜80% |
| 通常チーム vs ★3 鉄壁（期待値最善の采配 / ランダム采配） | 31% / 12% |
| 通常チーム vs ★4 王都ロイヤルズ | 5〜12% |
| GOD ELEVEN vs 通常5チーム | 96〜100%（平均4〜7得点） |
| GOD ELEVEN vs THE ELEVEN | 約80%（確実ではない） |
| 通常（引き直し5回）vs THE ELEVEN：標準戦術 / 攻撃的戦術 | 3% / 1% |
| 通常（引き直し5回）vs THE ELEVEN：低いライン＋消極プレス＋遅いテンポ | 6〜7% |

- 采配の良し悪しで勝率が大きく変わる（ランダム采配12% → 最善采配31%）
- 裏ボスには「守って走らせ、終盤に仕掛ける」戦術が有効で、無策より勝率が数倍になる
- 数値は叩き台。実プレイでのテストを前提に `data/` と engine の係数を調整してください
