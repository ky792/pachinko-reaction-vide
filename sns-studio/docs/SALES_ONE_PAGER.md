# SNS投稿の「下書き → 承認 → 出力」をまとめて整えます

**記事や商品の情報を1回入れるだけで、X・Instagram・Threads 向けの投稿案を9案。
担当者がスマホで承認したものだけが、投稿用の文章になります。**

---

### こんなお悩みに
- ブログや新商品を出しても、SNS用に毎回書き直すのが手間
- 外注・スタッフが書いた投稿を、公開前に確認する仕組みがない
- 「PR表記の付け忘れ」「誇大な表現」「文字数オーバー」が怖い
- AIを使いたいが、費用や勝手な投稿が心配

### できること
| | |
|---|---|
| **まとめて作成** | 1件の情報から、SNSごとに「要点まとめ／共感・問いかけ／告知」の3案 |
| **自動チェック** | 文字数・ハッシュタグ数・【PR】表記（ステマ規制）・誇大表現を承認前に警告 |
| **承認の記録** | 誰がいつ承認したかを記録。承認後に文章が書き換わったら自動で出力停止 |
| **スマホで完結** | Google スプレッドシートのアプリで、チェックとプルダウンだけで承認 |
| **勝手に投稿しない** | 投稿は人が最後に行う設計。自動投稿の機能そのものを持ちません |

### 流れ
`情報を入力` → `投稿案を自動作成（9案）` → `スマホで確認・修正` → `承認` → `投稿用に出力` → `各SNSに投稿`

### 費用の考え方（透明性を重視）
- **基本機能は月額ツール代0円**（Google スプレッドシート上で動作）
- AIで文章を作る場合だけ、お客様のAPIキーで従量課金（目安：1件9案で約10円／2026年10月時点）。使うかどうかはお客様が決められます
- 自動予約投稿は、各SNSの公式API・審査・料金をご確認いただいたうえで追加対応
