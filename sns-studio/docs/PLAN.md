## 2. 既存リポジトリから参考にした点（コードは共有していません）

- **スマホからGitHub Actionsを動かす運用**：既存の「Run workflow → Artifactで受け取る」流れを踏襲し、`SNS studio demo` ワークフローを追加
- **無料ツール優先**（edge-tts 採用と同じ方針）：生成は無料のテンプレート、AIは任意・明示的な有料オプション
- **台本（入力）→自動生成→人が確認**という制作パイプラインの考え方、`test-lab-motion.yml` と同様の「PR時だけ対象パスをテスト」の形
- `sns-studio/` は他のフォルダを読み込まないので、そのまま別リポジトリへコピーして独立させられます

## 3. 構成

```
            ┌──────────── core/sns-core.js（生成・チェック・承認・出力・CSV。通信なし）
            │                     ▲ build.js で同じコードを埋め込む
入力(記事/商品) ─┼─ web/index.html …… スマホのブラウザ。データは端末内（localStorage）
            ├─ apps_script/*.gs … Google Sheets。チーム共有・承認の記録
            └─ cli.js ………………… PC/GitHub Actions。CSV入出力・デモ・（任意）AI生成
                                         └ core/ai-adapter.js（--ai --confirm-cost のときだけ）

状態: 下書き ──承認(要:承認者名・エラーなし)──▶ 承認済 ──出力(本文ハッシュ一致)──▶ 出力済
        ▲   └─差戻し(要:理由)─▶ 差戻し                 │
        └────────── 本文を直すと必ず下書きに戻る ◀────────┘
出力済 = 手動投稿用の文章ファイル／シート。SNSへの送信はしない
```

## 4. 実装計画（段階）

| 段階 | 内容 | 状態 | 費用 |
|------|------|------|------|
| 0 | 無料デモ（本ディレクトリ）：テンプレート生成・承認フロー・Sheets・Web・CLI・テスト・資料 | **完了** | 0円 |
| 1 | 顧客ごとの導入：テンプレート文面・NGワード・ハッシュタグを業種に合わせて調整、顧客のGoogleアカウントにシート設置 | 受注後 | 0円（Google無料枠） |
| 2 | AI生成の本番利用：顧客のAPIキーで `--ai` を利用、月の上限金額を顧客側で設定、出力品質の確認 | 顧客の同意後 | 従量課金（下表） |
| 3 | 予約投稿の連携：承認済だけを各SNSの公式APIへ渡す（承認ゲートは維持） | 顧客の同意・審査後 | SNS側のAPI料金・審査 |

## 5. 不足機能（本番運用までに必要なもの）

| 機能 | デモの状態 | 本番で必要なこと | 費用・注意 |
|------|-----------|------------------|-----------|
| 外部SNSへの投稿・予約 | **意図的に未実装** | X API / Instagram Graph API / Threads API の連携。承認済・ハッシュ一致のものだけ送るゲートを必ず残す | X API は利用量によって有料プランが必要。Meta系はビジネスアカウントとアプリ審査が必要（いずれも最新条件を公式で確認） |
| 承認者の本人確認 | 名前の入力のみ（なりすまし可能） | Sheets のシート保護・編集者の限定、Googleアカウントでの記録（インストール型トリガー） | 無料（権限承認の手順が増える） |
| 画像・動画の添付 | なし（文章のみ） | 画像の保存場所（Drive 等）と投稿案への紐づけ、画像生成AIの利用可否 | 画像生成は別途従量課金 |
| 記事URLからの自動入力 | なし（手入力） | 記事本文の取得（スクレイピングの可否確認）または CMS・ECのAPI連携 | サイトの利用規約確認が必要 |
| CLI ⇔ Sheets の自動同期 | CSVの手動ダウンロード／取り込み | Google Sheets API（サービスアカウント） | 無料枠内。認証情報の管理が必要 |
| 複数人での同時利用 | Web版は端末内だけ | 共有はSheets版を使う／サーバー付きの版を作る | サーバー費用が発生する場合あり |
| 表現チェック | 簡易NGワード・PR表記・文字数・タグ数 | 業種別辞書（薬機法・景品表示法など）、専門家の確認フロー | 法務確認は別途 |
| 文字数の正確さ | X は全角2・URL23の近似（絵文字の結合文字などは誤差あり） | 公式の twitter-text ライブラリで計数 | 無料 |
| 効果測定 | なし | 各SNSのインサイト取得・シートへの集計 | API条件による |
| 通知 | なし | 承認待ちのメール／チャット通知（Apps Script のメール送信など） | 無料枠内 |
