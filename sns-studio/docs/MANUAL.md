# 利用マニュアル

記事や商品の情報を入れると、SNS投稿の案を複数作り、**人が承認したものだけ**を投稿用の文章として出力します。

- 既定では **AIを使いません（無料）**。決まったテンプレートで文章を作ります
- どの使い方でも **SNSへ自動投稿はしません**。出力された文章を、各SNSのアプリにコピーして手動で投稿します
- 使い方は3通りあります。スマホで使うなら **A（Google Sheets）** がおすすめです

| | A. Google Sheets | B. Web画面（1ファイル） | C. CLI（パソコン） |
|---|---|---|---|
| スマホ操作 | ◎ Sheetsアプリでそのまま | ○ ブラウザで開ければ使える | △ GitHubアプリからActions実行のみ |
| チームで共有 | ◎ | ×（その端末だけに保存） | △ CSVで受け渡し |
| 準備 | 初回だけパソコンで貼り付け | ファイルを開くだけ | Node.js 18以上 |
| AI生成（有料・任意） | なし | なし | あり |

---

## 状態の流れ（共通）

| 状態 | 意味 | 次にできること |
|------|------|----------------|
| 下書き | 作ったばかり／直した直後 | 承認する（承認者名が必要）・差戻す（理由が必要） |
| 承認済 | 公開してよいと判断済み | 出力する。本文を直すと**自動で下書きに戻る** |
| 差戻し | 直しが必要 | 本文を直す → 下書きに戻して再承認 |
| 出力済 | 投稿用の文章として書き出し済み | コピーして手動で投稿 |

自動チェック（✖ はエラーで承認不可、△ は注意）:

- 文字数（X は全角2・半角1・URL23で280まで、Instagram 2,200、Threads 500）
- ハッシュタグの数（X 2個、Instagram 10個、Threads 1個まで）
- 誇大・断定表現（「絶対」「最安値」など。`core/templates.json` の `ng_words`）
- 広告案件の【PR】表記（ステルスマーケティング規制への対応）
- 記事URLの入れ忘れ（△）

承認すると、そのときの本文の指紋（ハッシュ）を記録します。**承認後にシートなどで本文を書き換えると、出力の対象から外れます**（再承認が必要）。

## A. Google Sheets で使う（スマホ向け・チーム向け）

### 初回の設定（パソコンで1回だけ・約5分）

1. Google ドライブで新しいスプレッドシートを作る
2. メニュー「拡張機能 → Apps Script」を開く
3. 最初からある `コード.gs` の中身を消し、`apps_script/Code.gs` の内容を貼り付ける
4. 左の「＋ → スクリプト」で `Core` というファイルを作り、`apps_script/Core.gs` の内容を貼り付ける
5. 保存して、上部の関数選択で `setupSheets` を選び「実行」
   - 初回だけ「承認が必要です」と出ます。このスクリプトは**このスプレッドシートの読み書きだけ**を行い、外部への通信はしません
6. スプレッドシートに戻ると「入力／下書き／出力／ログ」シートができています
7. （任意）関数 `insertSamples` を実行すると、記事と商品のサンプルが入ります

※ 課金は発生しません。外部公開もされません（共有設定は通常のスプレッドシートと同じです）。

### 毎日の使い方（スマホの Sheets アプリでOK）

1. **入力シート**：1行に1件、記事または商品の情報を書く（id・種類・タイトル・概要は必須。要点はセル内改行で3つまで）
2. 行の左端「生成する」に**チェック** → 数秒で「下書き」シートに投稿案ができ、チェックは自動で外れます。結果列に件数かエラーが出ます
3. **下書きシート**：本文（text列）を読む・必要なら直す
4. 承認するには、`approver` 列に名前を入れてから、`status` を「承認済」に変更
   - 名前が空、またはエラー（✖）が残っていると、自動で「下書き」に戻り、理由がセルのメモに残ります
5. 差戻すには、`approver` と `comment`（理由）を入れてから `status` を「差戻し」に
6. **出力シート**：1行目の「出力を実行」に**チェック** → 承認済の案が下に書き出され、下書きシート側は「出力済」になります
7. 出力シートの文章をコピーして、各SNSアプリから投稿します

- 同じ id で作り直すと、下書き・差戻しの案は新しい内容で上書き、承認済・出力済の案は保護されます
- 操作の記録は「ログ」シートに残ります
- スマホのアプリではメニュー「SNS承認」は表示されませんが、上の操作はすべてチェックとプルダウンだけでできます

## B. Web画面で使う（`web/index.html`）

1ファイルで完結し、インターネット接続なしでも動きます。データはその端末のブラウザの中だけに保存されます。

**開き方**
- パソコン：ファイルをダブルクリック
- Android：GitHub アプリ → Actions →「SNS studio demo」→ 実行結果の Artifacts（`sns-studio-demo`）をダウンロード → zip内の `sns_studio_demo.html` を Chrome で開く
- iPhone：ファイルアプリのプレビューでは動かないことがあります。スマホでは **A（Sheets）** を使うか、パソコンで開いてください
- 社外の人に見せるためにインターネット上へ公開する場合は、公開してよいか事前に確認してください（このデモは自動で公開しません）

**操作**
1. ①入力：「記事サンプル」または「商品サンプル」→「投稿案を作る（無料）」
2. ②確認・承認：一番上に名前を入れる → 各案の「承認する」「差戻す（理由入力）」。本文はその場で直せます（直すと承認はやり直し）
3. ③出力：「承認済を出力する」→ 出力済の案の「文章をコピー」→ SNSアプリに貼り付け
4. 「全件をCSVで保存」で Google Sheets 用の CSV を保存できます（Sheets の「ファイル → インポート → 現在のシートを置換」で下書きシートに読み込めます。その際「テキストを数値、日付、数式に変換」は**オフ**にしてください。承認の照合用の値が数値に変わると出力されなくなります）。逆にシートからダウンロードしたCSVを「CSVを読み込む」で取り込めます

## C. CLI で使う（パソコン・GitHub Actions）

Node.js 18 以上があれば、追加インストールなしで動きます（`sns-studio/` フォルダで実行）。

```bash
node cli.js demo                                   # サンプルで一連の流れ → work/demo/
node cli.js generate samples/article.json          # 下書きを作る（work/drafts.csv）
node cli.js list                                   # 一覧
node cli.js show A001-x-summary                    # 本文を見る
node cli.js approve A001-x-summary --by 山田        # 承認
node cli.js reject A001-x-question --by 山田 --comment "もっと短く"
node cli.js edit A001-x-question --text "新しい本文"  # 直す（承認は取り消し）
node cli.js export                                 # 承認済だけ → work/export/（CSVと手動投稿用Markdown）
node cli.js import シートからダウンロードした.csv     # Sheetsの状態を取り込む
npm test                                           # テスト
```

入力ファイル（JSON）の項目: `id` `type`（article / product）`title` `summary` `points`（配列、3つまで）`url` `price` `target` `cta` `brand` `hashtags`（配列、#なし）`is_pr`（true/false）。`samples/` を参考にしてください。

**スマホから**：GitHub アプリ → Actions →「SNS studio demo」→ Run workflow。テストとサンプルデモが実行され、結果（Web画面・スクリーンショット・承認済の文章）が Artifacts に入ります。公開リポジトリでは無料です。

## AI生成を使う場合（任意・有料）

> 使わなければ一切費用はかかりません。使う前に、費用と、入力内容がAnthropic社のAPIに送られることを了承してください。

1. 費用の目安を見る：`node cli.js cost --items 10`（既定モデル `claude-opus-5-5`：入力 $4／出力 $20 ／100万トークン、1件=9案で約10円。2026-10時点、公式で再確認）
2. 自分の Anthropic アカウントで API キーを発行し、支払い設定と**利用上限額**を設定する
3. 公式SDKを入れる：`npm install @anthropic-ai/sdk`
4. 実行：`ANTHROPIC_API_KEY=... node cli.js generate samples/article.json --ai --confirm-cost`
   - `--confirm-cost` がないと、料金の目安を表示して止まります（課金されません）
   - モデルを変える場合は `--model claude-haiku-5-5` など（安いほど文章の質は下がる傾向）
5. AIの案も必ず「下書き」になり、同じチェックと承認が必要です

## 文面・ルールを変える

- 文面：`core/templates.json` の `templates`（`{{title}}` などの差し込み、`{{#price}}…{{/price}}` は値があるときだけ表示）
- NGワード：同じファイルの `ng_words`
- 変更後は `node build.js` で Web画面と `apps_script/Core.gs` を作り直し、`npm run snapshot` で期待値を更新して `npm test`。Sheets 版は新しい `Core.gs` を貼り直してください

## 困ったとき

| 症状 | 対処 |
|------|------|
| Sheetsで「生成する」にチェックしても何も起きない | 初回設定の5（`setupSheets` の実行と権限の承認）が済んでいるか確認。結果列のエラー表示を確認 |
| 承認済にしても下書きに戻る | status のセルのメモに理由があります（承認者名なし・✖エラーあり） |
| 承認済なのに出力されない | 承認後に本文が変わっています。下書きに戻して再承認してください（ログシートに理由） |
| Web画面のデータが消えた | ブラウザのデータ削除・プライベートモードでは保存されません。CSVで保存しておくと安全です |
