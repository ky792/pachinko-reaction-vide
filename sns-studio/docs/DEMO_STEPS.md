# デモ操作手順（商談用・約5分）

## 事前準備（前日まで）

- [ ] Google Sheets 版を自分のアカウントに設置済み（`docs/MANUAL.md` の A「初回の設定」）。`insertSamples` でサンプルを入れておく
- [ ] スマホに Google スプレッドシートのアプリを入れ、そのシートを開けることを確認
- [ ] 予備として Web 画面（`web/index.html`）をパソコンかAndroidで開けるようにしておく
- [ ] 下書き・出力シートを空にしておく（前回のデモの残りを消す）
- [ ] 見せるのはサンプルの架空データだけ。お客様の実データを使う場合は事前に了承をもらう

## 本番の流れ

| 時間 | 操作（スマホ） | 話すこと |
|------|----------------|----------|
| 0:00 | 入力シートを見せる | 「ブログ記事や商品の情報を1行書くだけです。今日はサンプルの記事と商品を使います」 |
| 0:30 | 記事サンプルの行の「生成する」にチェック | 「この1回で、X・Instagram・Threads向けに3案ずつ、合計9案できます」 |
| 1:00 | 下書きシートで X とInstagramの案を見比べる | 「SNSごとに文字数やハッシュタグの数を自動で合わせています。Xは全角を2文字と数える公式ルールに沿っています」 |
| 1:45 | 商品サンプルも生成 → 本文の先頭の【PR】を見せる | 「広告案件は【PR】を自動で付けます。消すとエラーになり承認できません（ステマ規制対策）」 |
| 2:30 | 承認者を空のまま status を「承認済」に → 下書きに戻る様子 | 「誰が承認したかを必ず残します。名前がないと承認できません」 |
| 3:00 | approver に名前を入れて「承認済」に | 「これで公開してよい状態です」 |
| 3:20 | 承認済の案の本文を少し書き換える → 「下書き」に戻る | 「承認したあとに誰かが文章を変えると、承認は自動で取り消されます」 |
| 3:50 | 別の案を承認 → 出力シートの「出力を実行」にチェック | 「承認済のものだけが投稿用の文章になります。**ここからSNSへ自動で投稿はしません**。最後に人がコピーして投稿するので、誤投稿が起きません」 |
| 4:30 | ログシートを見せる | 「いつ誰が何をしたか残るので、後から確認できます」 |
| 4:45 | 費用の説明 | 「ここまで全部、ツール代は0円です。AIで文章を作りたい場合だけ、お客様のAPIキーで1件約10円の従量課金になります。使うかどうかは選べます」 |

## よくある質問への答え方

- **自動で投稿まではできない？** → 可能ですが、各SNSのAPI審査・料金が必要です。承認済だけを送る仕組みは残したまま追加できます（`docs/PLAN.md` 段階3）
- **AIの文章はおかしくならない？** → AIの案も必ず下書きになり、同じチェックと人の承認を通ります
- **うちの業種の言い回しにできる？** → 文面テンプレートとNGワードを業種に合わせて調整します（導入プラン）
- **データはどこに？** → お客様のGoogleアカウントのスプレッドシートだけです。外部に送信しません

## うまくいかないとき

- 「生成する」が反応しない → 数秒待つ／電波を確認。それでもダメなら予備の Web 画面で同じ流れを見せる
- Web 画面（予備）の操作: ①入力「商品サンプルを入れる」→「投稿案を作る」→ ②名前を入れて「承認する」→ ③「承認済を出力する」→「文章をコピー」
