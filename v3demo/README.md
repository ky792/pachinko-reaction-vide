## ショット（8ショット・7種類の画面型）

| 時間 | 画面型 | 中身 | 素材 |
| --- | --- | --- | --- |
| 0.0–3.4 | 資料全画面＋見出し | ホールの情景にゆっくり寄る、金の見出し「MAX機の時代 〜2015年」 | hall_anime.png（AI生成イラスト、右上に「イメージ（イラスト）」表示） |
| 3.4–6.0 | 年表 | MAX機の帯が2015年末で途切れ、マーカーが2016年へ | 手続き生成 |
| 6.0–9.2 | 機種プロフィール | 金属調の背景、概念イラスト、機種名・導入年月・確率 | 概念イラスト（「実機写真ではありません」と表示） |
| 9.2–12.3 | キーナンバー | 円ゲージが約80%まで満ちる＋数字の意味 | 手続き生成 |
| 12.3–15.4 | カレンダー | 2016年3月→5月へ枠が移動、5月に「新しい内規」 | 手続き生成 |
| 15.4–19.0 | 要点カード | ボケ背景、見出し＋項目が1つずつ書かれる | 手続き生成 |
| 19.0–26.0 | 年表→比較 | 3月（北斗無双）と5月（適用開始）の位置関係→約80%と65%を並べ、指標が違う注記 | 手続き生成 |
| 26.0–30.0 | 問いかけ | ラボ背景に戻り、ナギとバクが登場 | lab_room.png、キャラ画像（ユーザー提供） |

常設は左上の番組タグと字幕（箱なし・縁取り）だけ。キャラは最後の4秒のみ。

## 事実と出典

- 真・北斗無双：2016年3月導入、大当たり確率1/319.7、ST130回・継続率約80%（ちょんぼりすた、1geki）
- 65%の内規：日工組の申し合わせ。2016年5月以降に新規納品される台が対象（nana press POKKA吉田コラム #10）
- 実機写真・公式資料は使っていない。実在の写真に見える素材は無い。

## 音

BGM・効果音とも自作の簡易シンセ（numpy）。ショットの切り替え、見出し、項目の出現、数字のカウントアップに合わせて鳴らしている。ナレーション音声なし。
