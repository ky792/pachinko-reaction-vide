Type Sheet

5タイプ定義（カラーと性格は固定）

同じタイプの男女は同じカラーとエンブレムを共有します。色だけで見分けさせないよう、各タイプに形の違うエンブレムを持たせ、色覚特性があっても識別できるようにします。色相は青・緑・赤・紫・金でおよそ60°以上ずつ離しています。

Expression Set

表情差分とセリフのトーン

各キャラクターに用意する立ち絵は1ポーズ×表情6種です。表情はゲーム内イベントに紐づけ、同じイベントでもタイプごとに出し方を変えます。第6の表情はタイプ固有の「らしさ」を担当します。

タイプ通常（ホーム）真剣（対戦開始）笑顔（正解）固有（誤答）喜び（勝利）鼓舞（敗北）
Staging Rules

ナビゲーターを「伴走者」に留める演出ルール

色の占有率は2割まで

画面の大半はニュートラルな夜色。タイプカラーはCTA・吹き出し枠・カットインだけに使い、ランクやRPなどプレイヤーの数値は常に白で表示します。

BASE 62%PLAYER 20%NAV 18%

立ち絵は画面下に小さく

ホームと対戦では直径58pxの丸アイコン＋吹き出し。立ち絵を大きく見せるのは、ナビ選択画面とカットインだけです。

○ 問題文と選択肢がいちばん大きい × 対戦中にキャラが問題文に重なる

動きはUI側に持たせる

キャラ自体はアニメーションさせません。吹き出しのポップ、1.5秒のカットイン、表情の差し替えで反応を表現します。

○ カットインは正解3連続・逆転・勝敗のみ × 毎問カットインで解答テンポを止める

セリフは事実＋一言

どのタイプでも、まずプレイヤーの数字や行動に触れてから性格を乗せます。正答率・解答時間・苦手単元など、実データを差し込める文型にします。

VEXの挑発は人格を攻撃しない

煽る対象は結果とスコアだけ。敗北時は必ず再戦の動機づけで締め、連敗時は挑発レベルを1段下げます。

無音でも伝わるタイポ

ボイスがない分、吹き出しの文字送り速度をタイプで変えます。LOGIC・ECHOはゆっくり、IGNITEは速く、VEXは一拍ためてから表示。
