# ChatGPT 画像生成 指示文

陣地の絵（建物20・台座8・庭14）を ChatGPT で作るための指示文です。
**手順：①最初に「共通ルール」を送る → ②1点ずつ「アイテム別」を送る → ③できた画像を ID のファイル名で保存して渡す**

---

## ① 最初に送る：共通ルール

```
これから、スマホ向け学習ゲームに登場する「陣地」のゲーム素材を、1枚ずつ作ってもらいます。
世界観は「近未来SF × 学園」。キャラクターは2Dアニメ調です。以下のルールを、これから作るすべての画像で必ず守ってください。

【視点】
・アイソメトリック（2:1、水平から約30°の見下ろし）。真上・真横・遠近法のパースは使わない
・すべての画像で同じ角度・同じ光の向きに揃える

【絵柄】
・2Dアニメ調のセル塗り（影は2〜3段）＋細くきれいな輪郭線
・光は左上から。右側の面はやや暗く、手前の面はさらに暗く
・基調色は白・明るいグレー・紺。落ち着いた高級感のある近未来の質感

【背景・出力】
・背景は完全に透過したPNG。黒や暗い色の背景も不可。対象の外側には何も描かない
・発光・グロー・光のもや・オーラは描かない（光の効果はゲーム側で付ける）。マゼンタ部分もベタ塗り＋陰影だけ
・地面の影は描かない
・文字・ロゴ・数字は描かない
・1枚に描くのは1つの対象だけ

【チームカラー（とても重要）】
・ゲーム内で「持ち主の色」に光る部分は、純粋なマゼンタ（#FF00FF）とその濃淡だけで塗る
・それ以外の場所には、マゼンタ・ピンク・紫を一切使わない
・マゼンタ部分にも陰影（明るい／暗い）は付けてよい

【サイズと配置】
・建物：1024×1536（縦長）。足元の中心が横中央・下端から15%の位置。横幅は80%以内。台座そのものは描かない
・台座：1536×1024（横長）。六角形の台座（角が上下に来る向き）。上面の中心が画像の中心。横幅は90%以内
・庭の小物：1024×1024（正方形）。横中央・下端に接地。横幅は70%以内

【禁止】
・実在の建物・城・ロゴのそっくりな模写、他の作品のキャラクターや意匠

理解できたら「了解」とだけ返してください。
```

## ③ うまくいかないときの言い方

| 症状 | 送る言葉 |
|---|---|
| 角度がばらばら | 「最初の画像と同じ30°アイソメトリックの角度に揃えて描き直してください」 |
| 背景が黒い・透過していない | 「形・角度・塗りはこのままで、背景を完全に透過にしてPNGで出し直してください。黒い背景も、周りの光のもやも消して、建物の外側には何も描かないでください」 |
| まわりが光っている（グロー） | 「発光・グロー・光のもやをなくしてください。マゼンタ部分はベタ塗りと陰影だけにしてください」 |
| 光る部分がピンクや紫になった | 「光る部分は純粋なマゼンタ #FF00FF だけで塗ってください。ほかの場所にピンク・紫は使わないで」 |
| 大きすぎる／はみ出す | 「対象を2割小さくして、足元の中心を下端から15%の位置に置いてください」 |
| 台座まで描いてしまう（建物） | 「台座や地面は描かず、建物だけにしてください」 |
| 絵柄が揃わない | 揃えたい画像を添付して「この画像と同じタッチ・同じ角度・同じ光で描いてください」 |
| 線がにじむ・細部がつぶれる | 「輪郭線をはっきりさせ、細部を少なめにしてシンプルにしてください」 |
