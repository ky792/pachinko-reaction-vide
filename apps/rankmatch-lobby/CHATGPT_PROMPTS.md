# ChatGPT 画像生成 指示文（かっこいい版）

陣地の絵（建物20・台座8・庭14）を ChatGPT で作るための指示文です。
**手順：①最初に「共通ルール」を送る → ②1点ずつ「アイテム別」を送る → ③できた画像を ID のファイル名で渡す**

## 方向性
- 伝統的なモチーフ（塔・城・門）を、**重厚な近未来SF建築として再解釈**する（例：五重塔 → 屋根が宙に浮く「五層軌道塔」）
- 素材は**白いセラミックの装甲パネル＋暗いガンメタル**。パネルの継ぎ目、排気口、ケーブル、留め具などの細部
- 光は**細い発光ラインとエネルギーの核だけ**。マゼンタは全体の15%以下。それ以外の光は白色光だけ
- **縦に鋭く伸びる強いシルエット**、わずかに左右非対称

## ① 最初に送る：共通ルール

```
これから、スマホ向け学習対戦ゲームの「陣地」のゲーム素材を1枚ずつ作ってもらいます。
世界観は「近未来SF × 学園」。プレイヤーの陣地は、知識の力で築かれた要塞です。
以下のルールを、これから作るすべての画像で必ず守ってください。

【デザインの方向性】
・伝統的なモチーフ（塔・城・門など）を、重厚でかっこいい近未来SF建築として再解釈する
・素材は「白いセラミックの装甲パネル」と「暗いガンメタル」の組み合わせ。ところどころに細い金の縁取り
・パネルの継ぎ目、排気口、ケーブル、留め具、段差などのメカニカルな細部を入れて密度を出す
・縦に鋭く伸びる強いシルエット。わずかに左右非対称にして単調にしない
・おもちゃっぽさ・かわいさは不要。高級感と緊張感のある「最終拠点」のような佇まい

【視点】
・アイソメトリック（2:1、水平から約30°の見下ろし）。真上・真横・遠近法のパースは使わない
・すべての画像で同じ角度・同じ光の向きに揃える

【絵柄】
・2Dアニメ調のハイクオリティなセル塗り（影は2〜3段）＋細くシャープな輪郭線
・光は左上から。右側の面はやや暗く、手前の面はさらに暗く。金属にはシャープなハイライト

【光る部分（とても重要）】
・ゲーム内で「持ち主の色」に光る部分は、純粋なマゼンタ（#FF00FF）で塗る
・マゼンタを使うのは、細い発光ライン・エネルギーの核・紋様だけ。面積は全体の15%以下。屋根や壁を丸ごとマゼンタにしない
・マゼンタ以外の光（窓など）は白色光だけ。ピンク・紫・青・緑などの色の光は使わない
・発光のにじみ・グロー・光のもやは描かない（光の効果はゲーム側で付ける）

【背景・出力】
・背景は完全に透過したPNG。黒や暗い色の背景も不可。対象の外側には何も描かない
・地面の影、文字、ロゴ、数字は描かない。1枚に1つの対象だけ

【サイズ】
・建物：1024×1536（縦長）。下のほうに足元を置き、台座そのものは描かない
・台座：1536×1024（横長）。六角形の台座（角が上下に来る向き）を中央に
・庭の小物：1024×1024（正方形）。中央に置き、下に接地

【禁止】
・実在の建物・ロゴのそっくりな模写、他の作品のキャラクターやメカのデザイン

理解できたら「了解」とだけ返してください。
```

| ダサい・普通すぎる | 「もっと重厚でかっこよく。伝統的な形をそのまま描かず、装甲パネルとメカニカルな細部で近未来の要塞として再解釈して。シルエットを鋭く」 |
| おもちゃっぽい | 「かわいさをなくして、高級感と緊張感を。金属のハイライトを強く、細部の密度を上げて」 |
| マゼンタが多すぎる | 「マゼンタは細い発光ラインと核だけにして、面積を全体の15%以下に。屋根や壁は白い装甲パネルとガンメタルに」 |
| 背景が黒い・透過していない | 「形・角度・塗りはこのままで、背景を完全に透過にしてPNGで出し直して。黒い背景も光のもやも消して、対象の外側には何も描かないで」 |
| まわりが光っている（グロー） | 「発光・グロー・光のもやをなくして。マゼンタ部分はベタ塗りと陰影だけに」 |
| 角度がばらばら | 「最初の画像と同じ30°アイソメトリックの角度に揃えて描き直して」 |
| 絵柄が揃わない | 揃えたい画像を添付して「この画像と同じタッチ・同じ角度・同じ素材感で描いて」 |
| 透過がどうしてもできない | 「背景だけを単色の緑 #00FF00 で塗りつぶして出力して」（こちらで抜きます） |
