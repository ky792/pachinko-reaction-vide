# 学習ランクマッチ：ナビゲーター選択 & ホーム 仕様

## 1. 体験の軸
- 受験勉強を「競技」として扱う。画面はゲームのロビーとして作り、学習管理アプリの見た目にしない。
- 主役はプレイヤー。ナビゲーターは専属の伴走者で、ランク・RP・学習量などプレイヤーの数値が常に画面の中心に来る。
- ボイスなし・フルアニメなし。立ち絵＋表情差分＋UI演出（ホログラム、走査線、ゲージ、ポップ）で見せる。

## 2. 画面フロー
```
#select（ナビ選択） --確定--> #home（ロビー）
#home --[ナビ変更]--> #select
```
- 初回は `#select`。確定後は選択内容を localStorage に保存し、次回は `#home` から始まる。
- ルーティングは `location.hash`（`#select` / `#home`）。

## 3. ナビ選択画面
| 要素 | 内容 |
|---|---|
| タイプタブ | 5タイプ。エンブレム（形）＋タイプ名＋色。色だけに頼らない |
| 男女トグル | タイプごとに男女を切り替え。タイプを変えても性別の選択は保持 |
| メインビジュアル | 選択中キャラを最大表示（スマホで画面高の約45%）。ホログラム台座・走査線 |
| プロフィール | 名前 / 肩書き / 一言 / 説明 |
| 性格 | 性格タグ3つ＋5軸パラメータ（分析・共感・熱量・刺激・探究） |
| 向いている学習スタイル | 箇条書き3つ＋「こんな人に」 |
| 確定ボタン | 画面下に固定（スマホ）。「{名前}と契約する」 |

## 4. ホーム画面（ロビー）
| 要素 | 内容 |
|---|---|
| ヘッダー | プレイヤー名・シーズン・通貨 |
| ナビ表示 | 立ち絵（背景にホログラムで大きく）＋吹き出し（時間帯・状況で変わる一言）＋表情タグ |
| 現在ランク | ランク記章・RP・昇格までの残り |
| 経験値 | Lv・EXPゲージ |
| 今日の学習量 | 学習時間と目標のリング、解いた問題数、正答率 |
| 次のおすすめ学習 | 弱点データから1件＋理由（ナビのタイプ別の推し文句） |
| ランクマッチ導線 | 最大のCTA。マッチ待ち人数・推定相手ランク |
| ミッション | デイリー/ウィークリー、進捗バー、報酬 |

## 5. タイプ定義（固定）
| タイプ | 色 | 性格 | 向いている学習スタイル | 男 / 女 |
|---|---|---|---|---|
| LOGIC | 青 `#3B9BFF` | 冷静・分析的・合理的 | 弱点分析→集中演習 | レイ / リゼ |
| HALO | 緑 `#34D399` | 優しい・伴走型・親身 | 毎日の習慣化・復習中心 | ハル / ミオ |
| IGNITE | 赤 `#FF4B5C` | 熱血・情熱的・行動的 | 短時間高密度・タイムアタック | カイト / アカリ |
| VEX | 紫 `#A970FF` | 挑発的・ライバル型 | 対戦・スコア競争 | トウマ / ルカ |
| ECHO | 金 `#F5C04A` | 知的・探究的・神秘的 | 原理理解・深掘り・記述 | ノエル / セラ |

### 男女差（特に HALO / ECHO）
- HALO ハル：頼れる先輩。落ち着いた低めのトーン、「〜だな」。計画を一緒に立てる。
- HALO ミオ：同級生の癒し系。共感と褒め、「〜だよ」。小さな達成を祝う。
- ECHO ノエル：書庫の賢者。丁寧語、論理で真理へ導く。「〜ですね」。
- ECHO セラ：星読みの巫女。詩的で謎めく、問いで返す。「〜かしら」。
- 他タイプは「同じ性格軸の中で温度差」を付ける（例：LOGIC レイ＝参謀／リゼ＝解析官）。

## 6. 実装構成（差し替えしやすさ優先）
```
apps/rankmatch-lobby/
  index.html            画面の器だけ（文言・画像なし）
  styles.css            トークンとコンポーネントの見た目
  data/navigators.js    キャラデータ（タイプ・男女・画像パス・セリフ・表情）
  data/mock-player.js   プレイヤーの仮データ
  js/components.js      UIコンポーネント（データを受け取ってHTMLを返す純関数）
  js/app.js             状態管理・ルーティング・イベント
  assets/navigators/    立ち絵（{typeId}/{charId}/{expression}.png）
```
- テーマカラーは `data/navigators.js` の `types[].color` だけが正。JSが `--theme` などのCSS変数に流し込む。CSSにタイプ名を書かない。
- 立ち絵は `characters[].portrait.{expression}` のパスで参照。画像がない/読めないときは `silhouette` 設定からSVGを生成して代替。
- 画像を差し替えるときは assets に置いてパスを書くだけ。コンポーネントは触らない。

## 7. 表情差分キー
`default`（通常） / `smile`（笑顔） / `serious`（真剣） / `special`（タイプ固有）
- ホーム：時間帯や状況で `default` / `smile` を出し分け。ランクマッチボタンにフォーカスで `serious`。
- 選択画面：プレビューは `default`、確定演出で `smile`。
