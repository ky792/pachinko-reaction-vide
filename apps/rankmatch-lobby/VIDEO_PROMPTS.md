# 決め技アニメ（AI 動画生成）指示文

陣地の決着で流す「決め技シーン」を、本物のアニメにするための指示文です。
画像から動画を作れるツール（ChatGPT の Sora、Kling、Runway、Luma など）で使います。

**手順**
1. `video-src/start_ja.png` など、機体ごとの「最初のフレーム」画像を添付する（緑背景・16:9・機体は左寄り）
2. 下の「共通」と「機体別」をつなげて送る
3. できた動画（mp4・4秒前後）を `fin_ja.mp4` などの名前で渡す → こちらで緑を抜き、マゼンタ部分をチーム色に変えて、決め技シーンで再生する

## 共通（毎回、機体別の前に付ける）
```
添付画像のロボットを主役にした、4秒のアニメーション動画を作ってください。

【絶対に守ること】
・背景は最初から最後まで単色の緑 #00FF00 のまま。地面、影、背景の模様や色の変化は入れない
・カメラは固定。パン、ズーム、手ブレは入れない
・ロボットのデザイン、色、装甲の形は添付画像から変えない。マゼンタ（#FF00FF）の部分はマゼンタのまま
・ロボットは画面の左寄りに立ち、右方向へ攻撃する。画面の外には出ない
・文字、ロゴ、字幕は入れない

【動きの流れ】
0〜1秒：構えて、力を溜める（体が少し沈み、目とコアが強く光る）
1〜2秒：右へ鋭く踏み込んで、武器で攻撃する
2〜3秒：画面の右側で技のエフェクトが大きく炸裂する
3〜4秒：元の立ち位置に戻り、決めポーズで止まる（最後の0.3秒は静止）

【絵柄】
・2Dアニメ調、セル塗り。重量感のあるなめらかな動き。ためとキレのあるメリハリ
```

## 機体別

```
技名は「墨染一閃」。筆刀を大きく振りかぶり、踏み込みと同時に一閃。刀身の穂先から黒い墨の斬撃が三日月形に飛び、右側で墨しぶきが大きく弾ける。背中の巻物のバインダーが翼のように開く。
```

```

```

技名は「ロゴス・ランス」。盾を構えて突進し、ペン先の槍で鋭く突く。槍の軌跡に光る文字列（読めない装飾的な文字）が流れ、右側で光の爆発。背中のアンテナの翼が大きく広がる。
```

```

## うまくいかないとき
| 症状 | 送る言葉 |
|---|---|
| 背景が緑でなくなる | 「背景は最初から最後まで単色の緑 #00FF00 のままにして。地面や影も描かないで」 |
| カメラが動く | 「カメラを完全に固定して作り直して。ズームもパンもなし」 |
| ロボットのデザインが崩れる | 「添付画像のロボットの形と色を最後まで保って。動きは控えめでいいので、デザインを変えないで」 |
| 動きがもっさりする | 「溜めはゆっくり、攻撃の瞬間は一気に速く。メリハリを強くして」 |
