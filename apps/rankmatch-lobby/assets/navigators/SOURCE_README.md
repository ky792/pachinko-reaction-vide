# PROJECT ACADEMY — AIナビゲーター採用ビジュアル

これはClaude / Claude Codeへ渡す画像ファイル一式です。画像はこのZIP内の `assets/navigators/` に実在します。`/mnt/data/` は作成側の環境のパスなのでClaude側では参照しないでください。

## 収録画像

| ファイル | タイプ | 固有カラー | 男性 / 女性 | 用途 |
|---|---|---|---|---|
| `logic.png` | LOGIC | 青 | レイ / リゼ | 冷静・分析型 |
| `halo.png` | HALO | 緑 | ハル / ミオ | 優しい・伴走型（改訂版） |
| `ignite.png` | IGNITE | 赤 | カイト / アカリ | 熱血・情熱型 |
| `vex.png` | VEX | 紫 | トウマ / ルカ | 生意気・挑発型 |
| `echo.png` | ECHO | ゴールド | ノエル / セラ | 知的・探究型（改訂版） |

## Claude Codeへの実装指示

- `assets/navigators` の実画像を確認してデザインを把握すること。各画像を読めない場合は読み込み方法を調べ、画像を見たと偽らないこと。
- 採用されたLOGIC / IGNITE / VEXのデザインを勝手に変更しないこと。
- HALOとECHOは改訂版の画像を最優先の参照元とする。旧画像に戻さないこと。
- 5タイプそれぞれに固有のテーマカラーを割り当て、同タイプの男女では共通カラーとすること。
- 2Dアニメ調の近未来SF×学力競争を軸にしたスマホ向け学習ランクマッチアプリ。
- キャラクターは学習補助用AIナビゲーター。声・フルアニメーションは不要。静止画＋テキストが基本。
- 画像内の文字や説明はあくまで画像生成の描写であり、アプリ実装時は別のHTMLテキストで表示すること。
- これらは紹介用キービジュアルであり、背景透過のキャラ単独立ち絵ではない。立ち絵や表情差分が必要なら別アセットとして作成・依頼すること。元画像から適当に切り抜いて完璧な立ち絵と扱わない。
- モバイル画面に画像を縮小して細かな文字を読ませるより、キャラの大きなビジュアルとアプリ側の可読テキストを組み合わせること。

## 注意

`halo.png` と `echo.png` は改訂版のタイプ紹介ビジュアルから切り出した横長画像で、他の3枚より縦解像度が小さいです。高解像度の単独キャラアセットではありません。UI試作ではこのまま使用し、必要が生じたら個別の立ち絵を追加制作してください。
