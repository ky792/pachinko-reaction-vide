# 陣地イラスト 制作規格（2D・アイソメトリック）

マイ陣地と対戦画面に出る陣地の絵の規格です。この規格どおりの PNG を置いて登録すれば、コードで描いた仮の絵と自動で入れ替わります。
**すべて見た目だけのアイテムで、対戦の強さには関係しません。**

## 1. 共通ルール
| 項目 | 規格 |
|---|---|
| 視点 | アイソメトリック（2:1、水平から約30°見下ろし）。真上・真横・パースは不可 |
| 向き | 六角形の台座の「角」が真上と真下に来る向き（仮の絵と同じ） |
| 光源 | 左上から。右側面は少し暗く、手前側面はさらに暗く（3段） |
| 絵柄 | 2Dアニメ調のセル塗り（2〜3段）＋細めの輪郭線。キャラのキービジュアルと並べて違和感のないタッチ |
| 背景 | 透過 PNG（アルファあり）。影は落とさない（地面の影はアプリ側で描く） |
| 色 | 「持ち主の色」（ナビのテーマ色）が入る部分は**色を付けず、白〜明るいグレーで塗る**。色は下のチーム色マスクで実行時に乗る |
| 文字 | 入れない（旗の文字・科目名はアプリ側で描く） |
| 禁止 | 実在の建物・城・ロゴの完全な模写、他作品のキャラや意匠、写真素材の切り貼り |

## 2. 種類ごとのキャンバスと基準点
| 種類 | 置き場所 | キャンバス | 基準点（アプリが合わせる位置） | 収める範囲 |
|---|---|---|---|---|
| 建物 | `assets/territory/skins/{id}.png` | 1024 × 1280 px | 台座の上面の中心 ＝ **横中央・下端から 160 px** | 横幅 820 px 以内（台座の上面に収まる）、高さは上端まで使ってよい |
| 台座 | `assets/territory/bases/{id}.png` | 1024 × 640 px | 台座の上面の中心 ＝ **画像の中心** | 六角形の上面の横幅 約 900 px、厚み（側面）は下に 120 px 程度 |
| 庭 | `assets/territory/garden/{id}.png` | 256 × 320 px | 地面に接する点 ＝ **横中央・下端** | 横幅 220 px 以内 |

- 建物は台座の上に乗るので、台座そのものは描かない（足元の床や土台までは描いてよい）。
- 台座の絵では、角の柱・縁の光・庭のスロット（左手前・右手前・奥）を空けておく。

## 3. チーム色マスク（`{id}_team.png`）
- 本体と**同じサイズ・同じ位置**の PNG。持ち主の色で光らせたい部分（屋根・旗・宝石・光る線など）だけを白で塗り、それ以外は透明。
- 白の濃さ（アルファ）が光の強さになる。アプリがナビの色（青・緑・赤・紫・金）で塗って、本体の上に加算で重ねる。
- 1つの絵で5色すべてに対応するため、本体側のその部分は無彩色にしておく。

## 4. 登録手順
1. 画像を上の置き場所に、ID どおりのファイル名で置く（例：`assets/territory/skins/skin_ja_goju.png`）。
2. `data/art-manifest.js` の該当する配列に ID を足す。マスクがあれば `team` にも足す。
3. 画面を開き直すと絵が入れ替わる。登録していない ID は仮の絵のまま（存在しない画像を読みに行かない）。

## 5. 画像生成の指示文（ひな形）
画像生成 AI を使う場合の指示文です。`{…}` を `ART_LIST.md` の各行で置き換えます。

```
Isometric 2:1 game asset, 30-degree top-down view, single object centered,
transparent background, no ground shadow, no text, no logo.
2D anime cel-shading with thin clean outlines, light from top-left,
near-future sci-fi academy world.
Subject: {英語の説明}.
Parts that will glow in the team color are painted plain white / light gray (no hue).
Canvas {キャンバス}, the object's base center at {基準点}.
```

チーム色マスクは、同じ構図で「光らせる部分だけ白、それ以外は透明（または黒で作ってから黒を透過）」として作ります。

## 6. チェックリスト
- [ ] 30°の見下ろし・左上光源になっているか（他のアイテムと並べてずれないか）
- [ ] 基準点が規格どおりか（台座の中心に建物が乗るか）
- [ ] 持ち主の色の部分が無彩色で、マスクと位置が一致しているか
- [ ] 文字・ロゴ・実在物の模写が入っていないか
- [ ] 透過の縁に白いフチやゴミが残っていないか
