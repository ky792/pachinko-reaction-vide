# 陣地イラスト 制作規格（2D・アイソメトリック）

マイ陣地と対戦画面に出る陣地の絵の規格です。この規格どおりの PNG を置いて登録すれば、コードで描いた仮の絵と自動で入れ替わります。
**すべて見た目だけのアイテムで、対戦の強さには関係しません。**

## 1. 共通ルール
| 項目 | 規格 |
|---|---|
| 視点 | アイソメトリック（2:1、水平から約30°見下ろし）。真上・真横・パースは不可 |
| 向き | 六角形の台座の「角」が真上と真下に来る向き（仮の絵と同じ） |
| 光源 | 左上から。右側面は少し暗く、手前側面はさらに暗く（3段） |
| 絵柄 | 2Dアニメ調のハイクオリティなセル塗り（2〜3段）＋シャープな輪郭線。伝統モチーフを重厚な近未来SF建築として再解釈（白いセラミック装甲＋ガンメタル、メカニカルな細部、鋭いシルエット） |
| 背景 | 透過 PNG（アルファあり）。黒背景・発光・グロー・光のもやは不可（光の効果はアプリ側で付ける）。影は落とさない |
| 色 | 「持ち主の色」で光る部分は**純粋なマゼンタ（#FF00FF）**。使うのは細い発光ライン・核・紋様だけで面積は15%以下。それ以外の光は白色光のみ。ピンク・紫・青・緑の光は使わない |
| 文字 | 入れない（旗の文字・科目名はアプリ側で描く） |
| 禁止 | 実在の建物・城・ロゴの完全な模写、他作品のキャラや意匠、写真素材の切り貼り |

## 2. 種類ごとのキャンバスと基準点
| 種類 | 置き場所 | キャンバス | 基準点（アプリが合わせる位置） | 収める範囲 |
|---|---|---|---|---|
| 建物 | `assets/territory/skins/{id}.png` | 1024 × 1536 px | 台座の上面の中心 ＝ **横中央・下端から 240 px（15%）**（アプリが絵の範囲を自動検出して合わせるので、多少ずれても可） | 横幅 820 px 以内、高さは上端まで使ってよい |
| 台座 | `assets/territory/bases/{id}.png` | 1536 × 1024 px | 台座の上面の中心 ＝ **画像の中心** | 横幅 1380 px 以内 |
| 庭 | `assets/territory/garden/{id}.png` | 1024 × 1024 px | 地面に接する点 ＝ **横中央・下端** | 横幅 720 px 以内 |

サイズは ChatGPT の画像生成がそのまま出力できる 3 種類（縦長・横長・正方形）に合わせています。

- 建物は台座の上に乗るので、台座そのものは描かない（足元の床や土台までは描いてよい）。
- 台座の絵では、角の柱・縁の光・庭のスロット（左手前・右手前・奥）を空けておく。

## 3. 持ち主の色（マゼンタ方式）
- 光らせたい部分（屋根・旗・宝石・光るライン・炎など）を**マゼンタ #FF00FF の濃淡**で塗る。陰影はそのまま残り、色だけがナビの色（青・緑・赤・紫・金）に置き換わる。
- 1枚の絵で5色すべてに対応する。マゼンタ以外の部分にピンク・紫を使うと誤って塗り替わるので使わない。
- 別ファイルのマスク（`{id}_team.png`、光らせる部分だけ白・ほかは透明）も引き続き使える。`data/art-manifest.js` の `team` に登録すると、マゼンタより優先される。

## 4. 登録手順
1. 届いた PNG を `python3 tools/clean_art.py 入力.png assets/territory/skins/skin_ja_goju.webp` で背景を抜きつつ WebP にして置く（配信は WebP。PNG の約8分の1）。
2. `data/art-manifest.js` の該当する配列に ID を足す。マスクがあれば `team` にも足す。
3. 画面を開き直すと絵が入れ替わる。登録していない ID は仮の絵のまま（存在しない画像を読みに行かない）。

## 5. 画像生成の指示文
ChatGPT 向けの指示文は `CHATGPT_PROMPTS.md`、制作対象の一覧は `ART_LIST.md`。

## 6. チェックリスト
- [ ] 30°の見下ろし・左上光源になっているか（他のアイテムと並べてずれないか）
- [ ] 基準点が規格どおりか（台座の中心に建物が乗るか）
- [ ] 持ち主の色の部分がマゼンタ（#FF00FF）で、ほかにピンク・紫が混ざっていないか
- [ ] 文字・ロゴ・実在物の模写が入っていないか
- [ ] 透過の縁に白いフチやゴミが残っていないか
