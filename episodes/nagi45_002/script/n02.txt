# ナギの45秒解析 #2「パチンコのボーダーの正体」（2026-11-27 確定台本・ユーザー指示書どおり）
# 前提：等価交換・出玉性能などの条件を固定した理論値。ボーダー17回転/1000円
# 平均回収額＝1000÷17≒58.82円/回転。コスト：15回転＝66.67円、17回転＝58.82円、19回転＝52.63円
# 1回転あたり：15回転＝−7.843円、19回転＝＋6.192円。1000回転：15回転＝−7,843円、19回転＝＋6,192円、差＝14,035円（丸める前の値で計算）
# 【導入】
バク: なぁナギ、パチンコの《ボーダー|ボーダー》ってあるやん？
ナギ: うん。
バク: 《ボーダー17回転|ボーダーじゅうななかいてん》の台が《15回転|じゅうごかいてん》しか回らんかったとして、たった《2回転|にかいてん》でそんなに変わるもんなん？
ナギ: じゃあ、ボーダーの仕組みから説明するね。
バク: 《あ、始まるんや……|あ、始まるんや。》
# 【45秒解説】
ナギ: ボーダーとは、期待収支がプラスマイナスゼロになる回転率のこと。
ナギ: 例えば、等価交換でボーダー17回転の台なら、通常時《1回転|一回転》あたりの平均回収額は約59円。
ナギ: でも、1000円で15回転しか回らなければ、《1回転|一回転》に約67円かかる。
ナギ: つまり、《1回転|一回転》あたり、約8円のマイナス。
ナギ: 逆に、19回転なら、コストは、約53円。約6円のプラスになる。
ナギ: 1000回転させれば、その差は約1万4000円にもなるんだ。
ナギ: 平均回収額とコストが釣り合う境界線。それがボーダーだよ。
# 【掛け合い・オチ】
バク: なるほどなぁ。でも《ボーダー|ボーダー》超えてても負けるやん？
ナギ: 期待収支と実際の収支は、別物だからね。
バク: そもそも最近、《ボーダー|ボーダー》超える台なんか全然ないで？
バク: 《保留4つ溜まった|ほりゅうよっつ、たまった》だけで嬉しいもん。
ナギ: 随分ハードルが低いね。
バク: ほなメーカーが《ボーダー10回転|ボーダーじゅっかいてん》の台作れや！
ナギ: お店が8回転にするだけじゃない？
