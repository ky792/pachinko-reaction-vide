# 90秒品質検証 B2（声の聞き比べ用・音声のみ）

- 台本：`docs/proposals/ken_test90_B2_proposal.md` の21本＋語尾の型（`@dir tail=`）
- 声：`casting.json`（`voice/casting_b.json` からの変更点は `_note` に記載）

- 比較相手：`episodes/ken_test90_B2_base`（同じ台本を今の声の設定・語尾の型なしで読んだもの）
