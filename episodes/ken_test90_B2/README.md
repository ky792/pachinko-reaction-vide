## ナギのかすれ対策（2026-10-14 追記）
- 冥鳴ひまりは **約400Hzを超えるとかすれやすい**（同じ声の中で、400Hz超の区間は約5〜6割が雑音の多い声になる。400Hz未満は約1割）。
- 最初のB2は「声を少し高く」＋「強調語を強く」で、強調語（65%・80%・2016年3月・80%のまま）が約490Hzまで上がり、400Hz超の時間が約1.8%→6.0%に増えていた。
- `casting.json` の `pitch_max_hz=390`（と `pitch_min_hz=200`）で、上限・下限の手前から先を3割に縮める（`lab/tts.py` の `cap_pitch()`）。結果：400Hz超 6.0%→2.8%、最高 494Hz→432Hz。
- 話者同士のかすれ比較は、この測り方（HNR）では当てにならなかった（ずんだもん等でも高く出る）ので、話者選びの根拠には使わない。
