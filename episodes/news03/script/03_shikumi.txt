# 第2章 なぜアウトなのか（三店方式と風営法23条）
# 風営法23条1項：1号 現金・有価証券を賞品として提供すること、2号 客に提供した賞品を買い取ること を禁止（遊技場営業者）。出典：法律事務所の解説（mc-law.jp）・報道（khb「パチンコ店が客から直接景品を買い取ることは禁止」）
# 第三者が買い取る場合はこの規制の対象外：mc-law.jp の解説 →「って解説されてる」
# 2017年6月20日の政府答弁書（内閣衆質193第398号）：第三者が営業者と実質的に同一と認められる場合は23条1項2号違反となることがある／現金等提供禁止違反・賞品買取り禁止違反が増加傾向にあったため（処分の基準を）改正した。出典：衆議院の答弁書本文
# 未確認: 罰則の上限（拘禁刑・罰金の額）は一次資料で確認できていないので言わない
# 「条文に金額の線はない」：23条1項2号の文言に金額の要件はない（条文の要旨で確認）
