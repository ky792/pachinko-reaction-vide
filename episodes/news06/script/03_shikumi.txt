# 第2章 なぜ承認がいる？なぜ安くなる？
# ◎ 遊技機の増設・交替は、あらかじめ公安委員会の承認を受けなければならない（警視庁の手続案内・京都府警のQ&A）
# ◎ 新台（営業所に置かれたことのない検定機）：検定通知書の写しと、製造業者が作った製造番号などを書いた保証書面を付ける（警視庁）
# 「中身が検定に通ったものと同じだとメーカーが保証する書類」は保証書面の説明（ナギの言い換え）
# ◎ 実地調査＝警察職員が営業所に行って遊技機の性能などを確かめる（警察庁の広報資料）
# 「狙いは不正改造を防ぐこと／釘や基板をいじった台を置かせない」はナギの説明。不正改造の防止は警察庁の指導（グリーンべると 2025-11-10）にもある
# ○ 2025年11月5日、全日遊連が各県の組合に「警察庁が実地調査の一部省略を全国で行うと決めた」と通知。一部の県警の試行で支障なし（グリーンべると 2025-11-10）→「伝えてる」「らしい」
#   省略の具体的な中身・開始時期は各都道府県警察の判断で順次（記事に中身なし）→「一部を省く」とだけ言う
# ◎ 改正案の理由：実地調査の在り方を見直し、人件費・物件費が軽くなる（警察庁の広報資料・政令案の理由）
