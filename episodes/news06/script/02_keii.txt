# 第1章 何が変わる案か（手数料の標準額・認定とは・日付）
# ◎ 都道府県は施行令の額を標準として手数料条例を定める。標準額は原則3年ごとに見直す（警察庁の広報資料）
# ◎ 変更承認（未認定遊技機を含む）：5,200円＋1台40円 → 3,900円＋1台30円（政令案・グリーンべると）
#   新台（検定機）の入替もこの区分（茨城県警の手数料表「検定遊技機がある場合 5,200円＋1台40円」）
# ◎ 認定（検定を受けた型式の遊技機）：4,340円 → 3,030円、同じ型式の2台目以降 40円 → 30円（政令案・グリーンべると）
# ◎ 検定の期限は3年、期限切れの台を置き続けるには店が公安委員会の認定を受ける（ピーワールド 2012-12-14「3年間の検定期限切れ」、警視庁の手続案内）
#   認定の有効期間の年数は台本では言わない（一次資料で確かめていない）
# ◎ 意見募集は2026年12月5日まで（必着）、施行は2027年4月1日（政令案の附則）
# 計算：認定は約30%、承認の基本は25%下がる（コードで確認）。台本では割合は言わない（画面だけ）
