# 第2章 お金の流れ（なぜ団体のお金が抜けたとされるのか）
# ◎ 店の一部の機器（スマートユニット）の代金は、協議会を通って製造会社に払われる仕組み（デイリー・フィールドサービス）
# ◎ 製造会社に部品を納める業者に、実際より高い部品代を請求させた疑い／協議会が余分に払った差額がコンサル料などの名目で本人側へ（デイリー・時事見出し）
# 計算: 175,000,000 ÷ 24,500 = 7142.9 →「単純に割ると約7100円」（2万4500台は共同の記事がもと）
# 未確認: 2023年3月の業界紙（PiDEA X 2023-03-14）：2023年9月までの見込み スマート遊技機 96万1415台／専用ユニット 45万4609台（PSA加盟6社 36万6009台・認証協 8万8600台）。1出典 →「業界紙だと」
# 計算: 45.46万 ÷ 96.14万 = 0.47 →「半分もなかった」
