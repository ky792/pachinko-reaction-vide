# 第1章 何があったか（経緯）
# ◎ 2026年11月4日 警視庁が逮捕を発表／一般社団法人「電子認証システム協議会」の元代表理事／特別背任の疑い／損害 約1億7500万円（NHK は1億7000万円あまり）
# ◎ 手口：取引先（部品の業者）に実際より高い代金を請求させ、協議会が余分に払った差額がコンサル料などの名目で本人側に戻ったとみられる（デイリー・時事見出し・NHK・テレ朝系）
# 未確認: 「2022年4月〜2023年2月に納入されたスマートユニット2万4500台」は共同通信の記事がもと（デイリー・フィールドサービス）→「って報じられてる」
# 未確認: 「2003年設立・貸玉売上データの透明化が目的」はフィールドサービスのみ →「らしい」
# 未確認: 「数億円ほど」はテレビ朝日系（khb・KAB）のみ →「って報じられてる」
# 本人の認否は報道に無い → そのまま言う。使い道（不動産など）はテレ朝系のみで、個人を晒す方向なので言わない
# 「特別背任」の説明は一般的な意味（団体のために働く立場の人が、自分の利益のために団体に損害を与える罪）。罰則は言わない
