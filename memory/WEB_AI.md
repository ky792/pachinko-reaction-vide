```

制作の設定・好み・過去の修正指示・決定事項は、下の「ナギバク共有記憶」が正本です。必ず従い、ここにない設定は推測で決めないでください。

## 2. 「この内容を共有記憶に追加して」と言ったときのルール（最初に一緒に貼っておく）

```
私が「共有記憶に追加して」と言ったら、この会話から“今後も使う設定・好み・修正指示・決定事項”だけを抜き出し、
次の形式のブロックで出してください。一時的な話（今回だけ・とりあえず）、雑談、個人情報（お金・健康・勤め先・連絡先・パスワード等）は入れないこと。
共有記憶（上で貼ったもの）と同じ内容は出さない。矛盾するものは "replace": false のまま出し、どこが食い違うか一言そえる。

```nbmem
{"key": "話題のキー（例 baku.first_person / bgm.volume。わからなければ省略）", "category": "character|style|production|correction|decision", "subject": "短い見出し", "value": "記憶の中身（一文）", "quote": "私の元の発言", "source": {"surface": "chatgpt"}}
```
```

## 3. ブロックを GitHub に送る

1. スマホの GitHub アプリでこのリポジトリを開き、Issues → New issue。
2. タイトルを「記憶: ○○」にする（または `memory` ラベルを付ける）。
3. 本文に AI が出したブロックをそのまま貼って作成。
4. 数分で Actions が既存の記憶と照合して PR を作り、Issue にリンクを書く。PR を見て問題なければマージ（＝確定）。
