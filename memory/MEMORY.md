## 新台解説の制作方針（2026-11-22）

- 制作者本人はスロットにあまり詳しくない。そのため、スロットについてAIの生成した内容を未検証のまま「詳しいバク」の台詞にしない。
- 当面は、制作者が自分の知識・経験を活かしやすい **パチンコ新台解説を優先**する。公開本数の目安は **パチンコ7割・スロット3割**。比率は暫定的な目安であり、固定ルールではない。
- スロットの新台解説も今後扱う。ただし、仕様や仕組みを十分に調べ、正確性・面白さを検証できた機種に絞る。
- メーカー発表のスペックやゲームフローを機械的に読み上げるだけの動画は避ける。魅力、疑問点、気になる点、期待・懸念を、ナギとバクの自然な掛け合いで伝える。
- **情報の正確さと、ナギバクならではの会話・キャラの魅力を両立**させる。台本の評価・主張は根拠を確かめ、制作者自身が判断できるようにする。
