## 制作方針

- 企業案件も狙うので、台本でメーカー等をあまり下げず敵を作らない（2026-10-26・claude-chat・`script.no_enemies`）
- 昔の台は今の基準と照らし合わせて語る（今は1/399が普通なので初代の1/397を「重い」と言わない）（2026-10-21・CLAUDE.md（feat/kyu001-voice）・`script.history_context`）
- 公開時期で古くなる言い回し（初日取れるかな・導入予定・今の新台など）は使わない（2026-10-21・CLAUDE.md（feat/kyu001-voice）・`script.no_timely_phrases`）
- 1本に時間をかけすぎず、やりながら改善する本数重視（2026-10-29・claude-chat・`workflow.volume`）
- キャラの表情素材など過去に渡した素材を、再度用意するよう頼まない（2026-11-21・claude-chat・`assets.no_reask`）
- 台本の書き直し・声の作り直し・演出・書き出しは承認を待たずに最後まで進め、できたものを見せる（公開・削除などはしない）（2026-10-22・CLAUDE.md（feat/kyu001-voice）・`workflow.less_confirm`）
- キャラの声は台本どおりのTTS音声だけを使い、台本にない声（叫び・笑い・相づち等）は入れない。書き出し前に全行を文字起こしで照合し、合格した声だけを使う（2026-11-22・claude-chat・`voice.hallucination`）
