# 研究所UI「LAB OS」（プレビュー段階・本編には未適用）

ペルソナ5の「UIそのものが演出になる」考え方だけを借りた、ナギバク研究所独自のUI。
配色は濃紺ベース／シアン（ナギ・解析）／オレンジ（バク・ツッコミ）／赤（警告）だけ。

## デザイン言語（全パーツ共通）
- **チャンファー**：パネルの左上と右下を45°で落とす（`cham()`）
- **スラッシュ**：斜めの帯が切り込む。場面転換・結果発表・ツッコミで同じ形を使う
- **大きな数字**：少し傾け（skewX -8°）、シアンの色ブロックの影を落とす。発光はしない
- 研究所らしさは小さな英字ラベル（`DATA MONITOR`・`MODE ▸ ANALYSIS` など）だけで出す。無意味な数字や細かい枠は使わない

## 5つのパーツ
| パーツ | ファイル | 使いどころ | 派手さ |
| --- | --- | --- | --- |
| ① 通常解説 | `Subtitle.tsx` | 普段の会話（話者の色の名札＋字幕、`{…}` で強調、`\n` で改行） | 低（毎回） |
| ② 数値データ表示 | `DataPanel.tsx` | 線が走ってモニターが開く。行が順に出る。`scan` で解析ライン | 中 |
| ③ 警告・ツッコミ | `AlertCut.tsx` | `mode="tsukkomi"` 橙の帯だけ／`mode="alert"` 赤フラッシュ＋警告帯 | 高（ここ一番だけ） |
| ④ 解析結果発表 | `ResultReveal.tsx` | 暗転→帯→数字がドン→内訳バー。1本で1〜2回 | 最高 |
| ⑤ 場面転換 | `LabTransition.tsx` | 斜めの帯が抜ける。`at` の瞬間に中身を切り替える | 中 |

ほか：`RenUnit.tsx`（RNC-01：寝てる→起動→分析中→完了の表情と状態表示）、`LabStage.tsx`（背景・左上タグ・右上モード表示・キャラ）。

## RNC-01（レン）の解析シーン（`RenAnalysis.tsx`、約13秒）
寝て落ちてくる → 起動で飛び起きる → 考え中 → 煙で困り顔（`smoke={false}` で省略）→ スペックをタンクに読み込む → 疲れ顔で待つ
→ パネルに光線を当てて、回転数ごとの「次が当たる確率」のグラフを描く → RUSH本体で区切り（にっこり）→ 時短の引き戻しを足す（にっこり）→ 内訳バー → 合計（解説顔）。

数字は `spec` の確率と回数から計算する（トータル＝RUSH本体＋落ちた分×引き戻し）。実機に使うときは、メーカー公表の継続率とずれないか必ず照らし合わせる。
見本：`RenAnalysisDemo.tsx`（RUSH 1/99.9×130回＋時短 1/319×100回 → 73%＋7% ＝ 80%）。
