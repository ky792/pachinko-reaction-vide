# ナギバク研究所 新台解説シリーズ専用BGM

| ファイル | 内容 | 長さ | テンポ |
| --- | --- | --- | --- |
| `public/music/shinkai_op.wav` | オープニング：研究装置の起動 → 疾走 → **11.59秒でロゴの一撃** → 余韻 | 14.6秒 | 145BPM |
| `public/music/shinkai_loop.wav` | 解説中BGM：エレクトロファンク×近未来ジャズ。32小節で継ぎ目なしループ | 66.8秒 | 115BPM |

どちらも 48kHz・ステレオ・16bit。調は Dドリアン。2曲とも同じメロディモチーフ（`MOTIF`）を使っている（OP＝スーパーソウのリード、解説中＝1オクターブ下のベルで控えめに）。

## 作り直し方
```
python3 remotion/music/bgm_shinkai.py        # 2曲とも
python3 remotion/music/bgm_shinkai.py op     # OPだけ
python3 remotion/music/bgm_shinkai.py loop   # 解説中だけ
```
- テンポ：`OP_BPM` / `LOOP_BPM`、ハネ具合：`SWING`
- メロディ：`MOTIF` / `ANSWER`（16分の位置, MIDI番号, 長さ）
- コード進行：`SEC_A` / `SEC_B` / `FORM`、ベースの型：`BASS_PAT` / `BASS_FILL`、鍵盤のカッティング：`COMP`
- 楽器の音色：`synth.py`（`lead` `reese` `pluck_bass` `epiano` `bell` `pad` `kick` `snare` …）
- 各パートの音量：`make_op()` / `make_loop()` の `gains`

## 構成
- OP：0〜3.3秒 起動（サブの立ち上がり・だんだん速くなる起動音・ライザー・スネアのフィル）→ 3.3〜9.9秒 本編（4つ打ち・リースベース・モチーフ→答え）→ 9.9〜11.6秒 ビルド → 11.59秒 一撃（クラッシュ・インパクト・Dのコード）→ 余韻でフェード
- 解説中：A（8小節）→ A'（ベルでモチーフ）→ B（Gm9〜A7、ドラムを軽く・パッド）→ A''（モチーフの返し）。8小節ごとにタムのフィル、7・23・31小節目の終わりに「ぽよん」、16小節目に起動音の合いの手
- ナレーションの邪魔をしないように、鍵盤・ベル・パッドは 1〜4kHz を削ってある（2.5kHz −5dB、1.2kHz −2.5dB）
- ループ：最後の余韻を頭に重ねて切っているので、頭に戻っても音が途切れない

音源は外部のサンプルを使わず、numpy / scipy の自作シンセ（帯域制限オシレーター・FM・フィルター・畳み込みリバーブ・コンプ・サイドチェイン）だけで作っている。
