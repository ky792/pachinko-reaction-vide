# 素材仕様書（画像生成AIでの差し替え用）

いまは全素材をプログラムで描いています。下の仕様で画像を作り `assets/img/` に置き、
`js/assets.js` の同じキーにパスを書けば差し替わります。**1枚ずつ差し替えてOK**（残りはプログラム描画のまま）。

## 共通ルール

- 形式：**透過PNG**（背景のみ不透明PNG/JPG可）
- 世界観：**ダークファンタジー × コミカルな魔王経営**。シルエットは重厚、表情はコミカル
- 光源：右上の赤い月 ＋ 足元の松明（オレンジ）。縁に紫〜赤のリムライト
- 線：太めの暗いアウトライン（2〜4px相当）。パチスロ液晶らしい高彩度・高コントラスト
- 実在の作品・キャラクター・メーカーに似せない（オリジナルデザイン）
- キャラクター画像は **足元が画像の下端中央**、余白は上下左右に少し

### プロンプトの共通末尾（例）

```
original character design, dark fantasy with comedic tone, pachislot LCD game art style,
bold dark outline, rim light purple and red, high contrast, vivid colors,
transparent background, full body, centered, no text, no watermark
```

## 1. 魔物（256×256・右向き・足元が下端中央）

アニメは「待機の上下ゆれ・歩きの跳ね・攻撃の突進」をプログラムで付けます。**1ポーズ（待機）で十分**。
余力があれば `_attack`（攻撃ポーズ）も作っておくと後で切り替えに使えます。

| キー | 名前 | デザインの要点 | 戦力/人件費 |
|---|---|---|---|
| `monster.slime` | スライム | 緑のぷるぷるボディ、小さな紫の角2本、つり目だが愛嬌、片側だけ牙。いちばん安い新人社員 | 1 / 4G |
| `monster.goblin` | ゴブリン | 緑肌・長い尖り耳・黄色く光る目・ニヤけた歯並び、トゲ付き棍棒、茶色いチュニックにベルト | 2 / 8G |
| `monster.skeleton` | スケルトン | 赤く光る眼窩、鉄の兜（赤い房）、銀の片手剣、木と鉄の丸盾 | 3 / 12G |
| `monster.imp` | ガーゴイル | 紫の小悪魔、コウモリ翼、黄色い光る目、尾の先がスペード型、空中に浮く | 5 / 18G |
| `monster.dragon` | ドラゴン | 暗赤色の巨体、金色の腹板、角、大きな翼、口元に炎の光。最高級の幹部 | 10 / 35G |

## 3. 魔王（カットイン用・800×800・バストアップ・正面やや右向き）

画像の**下端中央が胸元**。肩から上がフレームに収まる構図。

- 青灰色の肌、巨大な湾曲した角（骨色）、小さな金の王冠、赤く光るつり目、尖った耳
- 高い襟の黒マント（内側が深紅）、トゲのある黒い肩当て、胸に赤い宝石
- **悪の大物だけど中身は中小企業の社長**というギャップ

| キー | 表情 | 使う場面 |
|---|---|---|
| `maou.grin` | 不敵なニヤリ。手に「魔王城 収支」と書かれた帳簿（文字は無しで可） | 腰部パネル・通常時 |
| `maou.laugh` | 口を大きく開けて高笑い | AT突入・上位AT昇格・総攻撃 |
| `maou.angry` | 牙をむいて激怒、拳を握る | 魔王降臨（CZ逆転） |
| `maou.shock` | 白目で汗、口があんぐり | レア役予告・赤字・CZ失敗 |

## 4. 魔王城（640×480・下端中央が崖の接地点）

レベルで段階的に発展する重要素材。**同じ構図・同じ崖で5枚**作ると切り替わりが気持ちよくなります。

| キー | 名称 | 内容 |
|---|---|---|
| `castle.1` | 廃墟の塔 | 崖の上に崩れかけた石の塔1本、木の足場、窓1つだけ灯る |
| `castle.2` | 小さな砦 | 胸壁のある本丸＋左右の城壁＋木の門 |
| `castle.3` | 魔王の城 | 左右に円錐屋根の塔、赤い旗、目の紋章の垂れ幕 |
| `castle.4` | 大魔城 | 中央に高い尖塔、内側にも塔、頂上に浮遊する紫の魔晶 |
| `castle.5` | 万魔殿 | さらに外塔、門の上に巨大なドクロ（目が赤く光る）、足元に溶岩の光、赤いオーラ |

## 8. 効果音・BGM（任意）

`js/assets.js` の `sounds` にパスを書くと内蔵シンセから差し替わります。

| キー | 用途 | キー | 用途 |
|---|---|---|---|
| `lever` | レバーオン | `stop` | リール停止 |
| `pay` | 払い出し | `rare` | レア役の告知音（キュイン系） |
| `fanfare` | AT・上位AT突入 | `hit` / `explode` | 攻撃・爆発 |
| `levelup` | 魔物レベルアップ | `alarm` | 勇者接近警報 |
| `win` / `lose` | ジャッジ勝敗 | `bgm.normal` `bgm.cz` `bgm.at` `bgm.upper` | 各モードBGM（ループ） |

## 優先順位のおすすめ

映像の印象への効き目が大きい順：

1. `maou.laugh` / `maou.shock`（カットインの見栄えが一気に上がる）
2. `castle.1`〜`castle.5`（経営の「発展」が一目で伝わる）
3. `monster.*` 5種と `hero.hero`
4. `bg.normal` / `bg.at`
5. `logo.main`
