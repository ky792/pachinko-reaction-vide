# 魔王経営記（仮） 再設計企画書 v2
### ― スロットで再建する魔王軍 ―

> 失った魔王が、謎のスロット台で魔物を呼び、軍を立て直し、もう一度世界を獲りにいく。
> **リールに並ぶのは図柄ではなく、自分の配下。** 軍を育てることが、そのまま台を組むことになる。

実際のお金・メダル・換金は一切ありません。回す力は魔王の「魔力」だけです。

---

## 0. 結論（先に要点）

**採用案：「魂札リール」― 自分の軍団でリールを組み、台の“気配”を読んで攻め時を決める侵略ゲーム**

1. **リール＝軍団**：召喚した魔物は「魂札」になり、リールの1コマとして書き込まれる。何をどれだけ入れるかで、揃いやすさ（確率）を自分で設計する。
2. **台には機嫌がある**：台の内部には「静寂 → ざわめき → 前兆 → 暴走」の隠れ状態がある。出目・ランプ・魔物の反応からそれを読み、**魔力を何枚つぎ込むか（BET）**を決める。パチスロの「前兆を読む楽しさ」を、運任せではなく**判断**に変える。
3. **勇者は確率を歪める**：勇者パーティーの技は、こちらのリールに直接干渉する（札を封印する、リールを逆回しにする、偽の前兆を見せる）。戦闘は、相手の次の手が見えるパズルになる。

この3つが同じリールの上で起きるので、スロット・育成・侵略が分かれない。

## 1. システム案の比較

| 案 | 中身 | 独自性 | スロットと他要素の一体感 | 未経験者 | 戦略性 | 映像・X映え | 判定 |
|---|---|:-:|:-:|:-:|:-:|:-:|---|
| **A. 召喚ガチャ×オートバトラー** | スロットで魔物を引き、盤面に並べて自動戦闘 | △ | △ スロット＝ガチャ機能だけ | ◎ | ○ | ○ | ジャンルの足し算。スロットが入口でしかない |
| **B. 侵略すごろく** | スロットの出目でマスを進み、止まった土地で戦う | △ | ○ | ◎ | △ | ○ | 判断の余地が小さく、運ゲーに寄る |
| **C. 魂札リール×前兆読み侵略（採用）** | 召喚した魔物でリールを組み、台の機嫌を読んで攻め、勇者のリール干渉と戦う | ◎ | ◎ リール自体が軍団・戦場・成長記録 | ○（導入設計で補う） | ◎ | ◎ | **世界観そのものがルールになっている** |
| **D. 魔王城カジノ経営** | 人間をカジノに集めて魔力を搾り取る | ○ | ○ | ○ | ○ | ○ | 賭博・換金を連想させるので不採用 |

**C を選んだ理由**：「スロットで魔物が召喚された」という設定を、そのまま一番深いルールにできるのはこの案だけです。リールの中身がプレイヤーの軍そのものなので、育てた結果が毎回の回転に表れ、回転の結果がまた軍を変えます。

## 2. ゲームの基本サイクル

### 1プレイ＝「1回の侵攻」（30〜45分）、1手番＝「1夜」（3〜5分）

```
┌─ 夜：召喚の刻（魔力で5〜8回転） ────────────┐
│  揃った魂札が働く → 金貨・魔石・魂の欠片       │
│  欠片が揃うと召喚陣 → 3体から1体を選んで入隊   │
└──────────────┬──────────────────┘
               ▼
┌─ 昼：魔王城 ───────────────────────┐
│  リール編集（札の入れ替え・並べ替え・除去）    │
│  施設の再建（＝台の「設定」が上がる）          │
│  3夜ごとに給料日（足りないと辞表）            │
└──────────────┬──────────────────┘
               ▼
┌─ 侵攻：世界地図から1地点を選んで攻める ───────┐
│  戦闘＝限られた回転数で勇者側を倒すパズル      │
│  勝てば領土・遺物・捕虜（勇者の札）を得る       │
└──────────────┬──────────────────┘
               ▼
        勇者の反攻（ときどき城に攻め込まれる）
               ▼
             次の夜
```

### 回転1回の流れ（すべての場面で共通）

1. **BET（魔力投入）**：1・2・3から選ぶ。多く入れるほど札の効果が倍になるが、魔力の消費も増える。
2. **レバー**：リールが回る。予告・前兆の演出はここで出る。
3. **停止**：押す順番は自由。押さなくても自動で止まる「おまかせ停止」がある。目押しの腕は要らない。
4. **魔眼（任意）**：止まったリールを1つだけ上下に1コマずらせる（回数制限あり）。**運を判断で補う唯一の割り込み**。
5. **解決**：中段ラインの3枚が左から順に効果を発動する。揃えば強い効果、隣り合う札同士にもシナジーがある。

## 3. スロットと侵略・育成・経営の連動

| つながり | 仕組み | プレイヤーが考えること |
|---|---|---|
| **育成 → スロット** | 魔物を召喚するとリールに札が増える。同じ魔物を3枚揃えると、その札が**進化**する（スライム → ボムスライムなど） | 進化させたい札を、揃いやすくなるだけ積むか |
| **スロット → 育成** | 揃った回数が札の経験値になる。出番のない札は**退屈して辞表を出す** | 札を詰め込みすぎると薄まり、腐る札が出る |
| **経営 → スロット** | 魔王城の施設を再建するほど台の**「設定（魔王の魔力）」が上がる**。リール枠の追加、魔眼の回数増、ライン追加 | 施設の再建と軍への投資の配分 |
| **スロット → 経営** | 金貨札で収入、給料日には在籍している札の数だけ給料がかかる | 強いけれど給料の高い魔物を何枚まで抱えるか |
| **侵略 → スロット** | 地域を制圧すると、その土地の「遺物」でリールのルールが変わる（例：上段も有効ラインになる） | どの順番で土地を取るか |
| **スロット → 侵略** | 戦闘は自分のリールで回すので、組んだ軍の質がそのまま戦力になる | 敵の妨害に強い構成を組めるか |
| **台の機嫌 → すべて** | 前兆・暴走中は召喚・戦闘・収入がまとめて強くなる | 暴走を、召喚の夜と戦闘のどちらに当てるか |

**台の機嫌（隠れ状態）**

| 状態 | 中身 | 読み取れるサイン |
|---|---|---|
| 静寂 | 通常 | 特になし |
| ざわめき | 前兆に上がりやすい | ベルキャットの鈴が鳴る、ランプが紫 |
| 前兆 | 3〜5回転以内に暴走しやすい | 魔王（失墜時）が身を乗り出す、特定の出目（リーチ目） |
| 暴走 | 数回転のあいだ全ラインが有効・効果2倍。勝ち続けると延長 | 筐体全体の演出 |

- 新人向けに**期待度★1〜5**を常に表示する。慣れた人向けには、★を消す「通の目」モードを用意する。
- 一定回数暴走しないと「魔導機の怒り」（天井）で必ず暴走する。ハマり続ける苦痛を残さないための仕組み。
- **パチスロらしい楽しさ（レア役・前兆・期待度・出目・連続演出）は、全部この台の機嫌の上に残る。**

## 4. 魔物ごとの個性と集める楽しさ

### 札の基本ルール（覚えるのは3つだけ）

- **中段に乗ると働く**（1枚の効果）
- **3枚揃うと大技**（同じ魔物3枚、または同じ種族3枚）
- **隣に並ぶと相性**（リール上で隣り合う札同士に効果がある）

### 種族（5つ）

| 種族 | 得意なこと | 代表 |
|---|---|---|
| 群れ（獣・スライム） | 数が増える・揃いやすい | スライム、ワーウルフ |
| 労働（ゴブリン・機械） | 金貨・城の工事 | ゴブリン、ゴブリンエンジニア |
| 不死（骨・亡霊） | 守り・しぶとさ | ボーンナイト、デュラハン |
| 魔術（茸・精霊） | 他の札を育てる・状態異常 | マジックマッシュ、マンドレイク |
| 博徒（スロット系） | 台の機嫌を動かす・一発の大きさ | ベルキャット、ダイスゴーレム、リールゴーレム |

### 魔物の個性（キャラクター一覧画像のラインナップから抜粋）

**かわいい枠（序盤〜／グッズの顔）**

| 魔物 | 中段での効果 | 3揃い・特徴 | 遊びの役割 |
|---|---|---|---|
| スライム | 攻撃1 | **分裂**：リールに自分が1枚増える | 揃えやすさを自分で増やす入門札 |
| ボムスライム | なし | **自爆**：左右の札ごと大ダメージ。自分は消える | 使い捨ての切り札 |
| ゴブリン | 金貨＋1 | 給料が安い働き者 | 経営の土台 |
| ゴブリンエンジニア | 隣のゴブリン×2 | 城の工事が1夜早まる | ゴブリンを束ねる |
| ベルキャット | 台を「ざわめき」へ上げる | 鈴が鳴ると前兆の確率UP | **台の機嫌を自分で動かす**唯一の手段 |
| マンドレイク | 叫ぶ：勇者全員が1回休み | 味方も1体気絶する | 強いけれど副作用がある |
| マジックマッシュ | 隣の札を毎夜少しずつ育てる | 胞子で進化を早める | 並び順が意味を持つ |
| チャレンジバニー | 「次の回転で揃えば×3、外せば気絶」 | 自分で賭けを宣言する | リスクを選ぶ楽しさ |

**格好いい枠（中盤〜終盤／強さの象徴）**

| 魔物 | 中段での効果 | 3揃い・特徴 | 遊びの役割 |
|---|---|---|---|
| ボーンナイト | 勇者の妨害を1回防ぐ | 盾を構える | 守りの要 |
| デュラハン | **頭と体が別々の札**。同じライン上に乗ると超攻撃 | 頭の札だけ別リールに置ける | 並べ方のパズル |
| ワーウルフ | 攻撃2 | 暴走中は×3 | 前兆読みと噛み合う |
| ダイスゴーレム | 攻撃1〜6（サイコロ） | 6が出ると次の回転も確定で6 | ハイリスク・ハイリターン |
| リールゴーレム | 止まったリールを1本だけ回し直す | 体の中に小さなリールを持つ | 運を引き直す |
| カジノシャーク | 隣の札を食べて自分を強化（デッキ圧縮） | 食べた札の能力を1つ覚える | 軍を削って尖らせる |
| ジャックポットドラゴン | 伝説。リールに1枚しか置けない | 3揃い（3リールすべてに乗る）で戦場を焼き払う | 終盤の夢 |

**集める楽しさ**
- **図鑑**：召喚・進化・特殊な揃い方（例：デュラハンの頭と体）で埋まる。
- **進化は「3揃い」で起きる**：スロットの言葉（揃う）がそのまま成長の言葉になる。
- **捕虜の札**：倒した勇者パーティーを自軍の札にできる。強いが、ときどき裏切る。
- **出番がないと辞表**：札が多すぎると、使われない札が辞める。詰め込むほど強くなるわけではない。

## 5. 運と戦略のバランス

| 運が決めること | 戦略で決めること |
|---|---|
| どの札が中段に止まるか | **リールの中身（どの札を何枚入れるか＝確率の設計）** |
| レア役・前兆が来るタイミング | **前兆を読んで、いつBET3にするか** |
| 召喚陣で出てくる3体 | **3体からどれを選ぶか** |
| | 魔眼を、いつ・どのリールに使うか |
| | リール上の並び順（隣接シナジー、魔眼でずらしたときの保険） |
| | 地図の進む順番、施設を建てる順番 |
| | 給料と戦力の釣り合い |

**目安**：1回転の結果はほぼ運、**1夜の結果は運5：判断5、1回の侵攻全体では運3：判断7**を目標にする。

**運のブレを抑える仕組み**
- 期待度の表示（新人向け）と、ほぼ見たまま信じてよい予告の作り
- 天井（魔導機の怒り）
- 低い振れ幅の札（ゴブリン）と高い振れ幅の札（ダイスゴーレム）を自分で選べる
- 戦闘では勇者の次の手（意図）が見える。見えない不利をつくらない

## 6. 序盤・中盤・終盤

魔王の3形態（失墜時 → 再建期 → 復権時）が、そのまま進行の節目になる。

| 段階 | 魔王 | 台とリール | 体験 | 主な敵 |
|---|---|---|---|---|
| **序盤：失墜（〜10分）** | しょぼくれた紫の塊 | リールは3本×8コマ。ほとんどが「がらくた札（石ころ）」で、スライム1枚だけ | 回すたびに石ころが魔物に置き換わっていく。**最初の召喚は台詞なしの決定演出**。最初の村を落とす | 村の自警団（妨害なし） |
| **中盤：再建期** | 本を読んで研究する姿 | 施設で台の設定が上がる。4本目のリール、斜めライン、魔眼が解放される。暴走が初めて起きる | 前兆読みとリール編集が噛み合いだす。給料日の辞表で笑い、勇者の反攻で城を守る | 聖騎士団（札を封印）、幻術師（**偽の前兆を見せる**） |
| **終盤：復権** | 真の姿 | 5本目のリール。伝説札が出る。地図の遺物でルールが大きく変わる | 自分だけの壊れた台が完成していく。王都を攻める | 勇者本人（リール逆回転、設定を1段下げる） |

**最終盤の種明かし（案）**：謎のスロット台の正体は、かつて魔王が封じた**原初の魔物**だった。設定を6まで上げると、台そのものが目を覚ます。エンディングで台が魔物として姿を現し、「次の侵攻」の開始時にその魔物を札として持ち込めるようになる。

## 7. 繰り返し遊びたくなる仕組み

- **1回の侵攻で完結する（ローグライト型）**：毎回、召喚陣の候補・地図・遺物が変わり、違う台に育つ。
- **持ち越すもの**：図鑑（召喚候補に入る魔物の種類）、魔王の称号、城の見た目、最初に持ち込める札1枚。
- **難易度の段階（勇者の加護）**：クリアするたびに、勇者側の妨害が1つずつ増える。
- **今日の台**：日替わりで同じ条件（設定・遺物・最初のリール）の侵攻。結果を画像1枚でXに投稿できる（最終リール・倒した勇者・侵攻日数）。
- **リーチ目図鑑**：暴走を告げる特殊な出目を集める。上級者向けのやり込み。

## 8. スロット未経験者への導入

- **用語を言い換える**：設定→魔王の魔力、小役→恵み、前兆→ざわめき、天井→魔導機の怒り、BET→魔力投入。スロットに詳しい人向けに「スロット用語で表示」も選べる。
- **押し順・目押しは使わない**：停止は好きな順番で押すか、おまかせ停止。腕の差が出るのは魔眼（判断）だけ。
- **最初の3回転は決め打ち**：1回目でスライムが中段に揃って召喚、2回目で金貨、3回目で初めての予告を見せる。
- **前回の試作機で作った「次に触るボタンを順番に光らせるガイド」を引き継ぐ**。
- **期待度★を常に表示**：演出の意味を知らなくても、盛り上がりの度合いが分かる。
- **説明文で教えずに、演出で教える**：揃うと魔物が飛び出す、外れると魔王がしょげる。

## 9. スマートフォンでの操作性

- 縦持ちで、**片手の親指だけで遊べる**ようにする。
- 画面配分：上の約60％を戦場・城・地図、下の約40％をリールと操作部にする。今の筐体レイアウトを小さくまとめた形。
- 操作：
  - レバー＝リール部分を下にスワイプ、またはレバーをタップ
  - 停止＝各リールをタップ（または停止ボタン）
  - 魔眼＝止まったリールを上下にスワイプ
  - 札の情報＝長押し
  - リール編集＝札をドラッグ
- 1夜は3〜5分。通勤の合間に1夜だけ進められる。オート回転と、戦闘の早送りもある。
- 振動（触覚フィードバック）：揃ったとき、前兆のとき、魔眼でずらしたとき。

### やめる

| 試作機の要素 | やめる理由 |
|---|---|
| 仮想メダル・CREDIT／PAYの7セグ表示・差枚・純増 | お金を連想させる。回す力は魔力だけにする |

| CZ・AT・上位ATという呼び方と、継続率の抽選 | 侵攻と台の機嫌（暴走）に置き換える。勝ち負けは抽選ではなく戦闘で決める |
| 人型の魔王 | 添付の設定画どおり、モンスターとしての魔王（3形態）に描き直す |
| 金色の装飾が多いUI | アート方針に合わせ、落ち着いた暗色と差し色に抑える |

## 11. 本作ならではのシステム（この世界観だから成り立つもの）

1. **魂札リール**：軍を育てる行為が、そのまま確率を設計する行為になる。「確率を組む魔王」という立場は、スロットで魔物を呼ぶ世界でしか成り立たない。
2. **設定＝魔王の魔力**：パチスロの「設定」が、魔王の力の回復と同じ意味になる。城を建て直すほど、台が魔王に味方する。
3. **前兆読み×魔力投入**：台の機嫌を読み、全力をつぎ込む瞬間を選ぶ。パチスロの「ここだ」という感覚を、運ではなく判断として味わえる。
4. **勇者は確率を歪める**：聖なる力とは「運を奪う力」。封印、逆回転、偽の前兆（ガセ予告）で、こちらの読みを崩しにくる。前兆読みが相手との駆け引きになる。
5. **揃えて進化・出番がなければ辞表**：「揃う」は成長、「腐る」は退職。リールの上の出来事がそのまま魔物たちの人生になる。
6. **捕虜の札**：倒した勇者が自分のリールに入る。世界を奪うとは、敵の運命まで自分の台に組み込むこと。

## 12. 戦闘の具体例（中盤・聖騎士団の砦）

```
勇者側：聖騎士（HP30）  次の手 →「中リールの最強札を2回転封印」
       僧侶  （HP15）  次の手 →「聖騎士を10回復」
こちら：回転数 5回 ／ 魔眼 1回 ／ 魔力 9

1回転目：BET1。デュラハンの体が中段、頭は上段に止まる
         → 魔眼で左リールを1コマ下げ、頭と体を同じラインに → 超攻撃で聖騎士に24
2回転目：聖騎士の封印で、中リールのデュラハンが使えない
         ベルキャットが鳴り、台が「ざわめき」へ
3回転目：リーチ目が出る（前兆）。ここで残りの魔力をつぎ込みBET3
         → 暴走突入。全ラインが有効になり、ゴブリン3揃いで金貨と攻撃 → 僧侶を撃破
4回転目：聖騎士を撃破 → 捕虜の札「聖騎士」を得る（強い守り札だが、10％で裏切る）
```

運（暴走が来るか）と判断（魔眼をどこに使うか、いつBET3にするか）が、1つの戦闘の中で重なる。

## 13. アート方針

- **高精細なドット絵**（キャラクターは64〜128px相当）。添付のキャラクター一覧の方向性を基準にする。
- **かわいい枠**は2〜3頭身、丸いシルエット、大きな目、色は2〜3色。**格好いい枠**は4〜6頭身、とがったシルエット、暗い色に差し色を1つ。
- 種族ごとに色の系統を決める（群れ＝青緑、労働＝緑と茶、不死＝骨色と青い炎、魔術＝紫と赤、博徒＝黒と赤）。札の小さな画像でも見分けられることを優先する。
- スロットの意匠（リール・サイコロ・カード・7）は**博徒の種族だけ**に入れる。全員には付けない。
- 魔王の3形態は、同じ角と同じ王冠で「同一人物」と分かるようにする。
- 過剰な金装飾・発光・きらめきは避ける。豪華さはここぞという場面（暴走・伝説札）だけに取っておく。
