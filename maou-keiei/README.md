## v1 ― 架空スマートパチスロ試作機シミュレーター

> **勇者を倒せ。赤字を出すな。**

## ゲーム性（仮仕様）

| 状態 | 内容 |
|---|---|
| **通常時「魔王城経営」** | 液晶は魔王城の断面図。金庫番のスライム、工事係のゴブリンが働く。実際の出目で**金庫に金貨**が入り（金貨揃い＝3枚など）、**10Gごとの給料日**に金庫から給料を一括で払う |
| **給料日の3G前** | 金庫が足りないときだけ、手前に**給料袋**と「あと金貨○枚」「金貨図柄1回で足りる」を表示。古株のゴブリンが無言で**辞表**を持って立つ。足りない残り3Gは押し順ナビ（給料日ナビ）が出る |
| **給料日（最終Gの第3停止）** | 足りれば給料袋が満ちて、ゴブリンは辞表をポケットへ。足りなければ本当に辞表を出して辞める。余裕で払える回は一瞬で流す |
| **経営判断（毎期）** | 最初の黒字の給料日に「ゴブリンを雇う／資金を残す」。以降は黒字の給料日ごとに**経営カード**を3枚から1枚：雇う・増築・特訓（全員Lv＋1）・魔物保険（次の給料不足を1回肩代わり）・資金を残す。停止ボタン（左・中・右）か液晶タップで選ぶ |
| **CZ「勇者襲来」** | 開始時に持っている魔物から**隊長**を1体選ぶ（スライム＝リプレイ×3、ゴブリン＝金貨揃い×2、スケルトン＝ハズレでも×3、ガーゴイル＝押し順正解×3、ドラゴン＝レア役×2）。7G以内に勇者のHPを0にすればAT。HPが残ると、雇った**新人が一拍遅れて追撃**。ダメージは乱数なし |
| **撃破ボーナス** | 勇者を倒すたび（CZ成功・継続ジャッジ勝利）に、ずっと効く強化を3枚から1枚：金貨揃い＋1枚、給料−2枚、勇者HP−10、新人の追撃＋4、勇者戦＋1G、ジャッジ勝率＋5% など |
| **AT「魔王経営RUSH」** | 突入時は報奨金が金庫に落ち、城の窓が下から順に点灯してからロゴ。1SET 20G、左に「今セットの育成No.1」を大きく表示。継続ジャッジではその魔物に見せ場 |
| **上位AT「世界征服RUSH」** | 昇格時は城門を内側から映し、門が開いて魔物が行進 → カメラが引いて12地域の地図。最初の村・鉄壁要塞・王都の3か所は専用の見せ場、他は旗が増えるだけでテンポよく |

確率・枚数・給料・経営バランスはすべて `js/config.js` で変えられます。

## 開発者用デモ機能（DEVボタン / Dキー）

- **モード呼び出し**：タイトル / 通常時 / CZ / CZ最終G / AT突入演出 / AT（即） / 継続ジャッジ / 上位AT昇格演出 / 上位AT（即） / エンディング
- **撮影用の再現**：「決算最終G・金貨で給与支払い成功」「決算最終G・支払い失敗（辞表提出）」「雇ったゴブリンの追撃で勇者撃破」（本編と同じ計算・演出を通すので何度でも撮れる）
- **次ゲームの成立役を予約・固定**（例：強チャンス目、魔王7揃い）
- 城Lv・資金・勇者接近度・魔物の雇用・レベルを操作
- **オートプレイ**（押し順ナビどおりに自動で止める・速度 x1/x2/x4）、演出の倍速
- 状態表示（差枚・戦力・ジャッジ勝率）

### URLパラメータ（録画の段取り用）

| パラメータ | 効果 |
|---|---|
| `?rec=1` | 撮影モード（DEVボタン・カーソルを隠す） |
| `?view=lcd` | 液晶のみ 16:9 表示（右下に小さくリールを合成）→ 横長動画用 |
| `?auto=1` | オートプレイで起動 |
| `?mode=at` | 起動直後にそのモードへ（`title` `cz` `at` `judge` `upper` `ending` など） |
| `?mute=1` | 消音 |

例：`index.html?rec=1&mode=title` → タイトル画面から録画開始。
筐体全体は **9:16（720×1280 基準）** で、スマホの縦長録画にそのまま合います。

```

  css/cabinet.css     筐体デザイン・ランプ・ボタン

  js/config.js        ★仮スペック（確率・払い出し・経営バランス・リール配列）
  js/assets.js        ★外部素材の登録表（画像・音のパスを書くだけで差し替わる）
  js/audio.js         内蔵シンセ効果音・BGM
  js/fx.js            演出部品（パーティクル・魔法陣・放射光・稲妻・カットイン・文字の叩きつけ・画面振動）
  js/castle.js        魔王城の断面図・給料袋・辞表・魔王軍の旗
  js/art.js           プログラム描画（魔物・勇者・魔王・城Lv1〜5・背景・図柄・ロゴ）
  js/reels.js         リール制御（最大4コマスベリ・押し順・出目判定）
  js/lcd.js           液晶エンジンと各モードのシーン
  js/seq.js           ★突入・昇格・終了などの演出シーケンス（ここに足すと新演出）
  js/game.js          ゲーム進行（抽選・経営・CZ・AT・ジャッジ・上位AT）
  js/cabinet.js       筐体の操作・7セグ・ランプ
  js/dev.js           開発者メニュー・オートプレイ
  docs/ASSETS.md      ★画像生成AI用の素材仕様書
```

### 画像素材の差し替え

1. `docs/ASSETS.md` の仕様で画像を作り、`assets/img/` に置く
2. `js/assets.js` の該当キーにパスを書く（例 `'monster.slime': 'assets/img/monster_slime.png'`）
3. 再読み込み。登録されていない素材はプログラム描画のまま動きます

効果音・BGMも同じく `sounds` にパスを書くと内蔵シンセから差し替わります。
