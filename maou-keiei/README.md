# 魔王経営記（仮） ― 架空スマートパチスロ試作機シミュレーター

> **勇者を倒せ。赤字を出すな。**
> ナギバク研究所・メカニック担当「バク」が開発した（という設定の）架空のパチスロ試作機です。
> **実際のお金・換金は一切ありません。** メダルはすべて仮想で、無くなると自動で補充されます。

ブラウザだけで動きます（インストール・ビルド不要。HTML / CSS / JavaScript のみ）。

## 動かし方

- **PC**：`maou-keiei/index.html` をダブルクリックで開く（Chrome / Edge / Safari）
- **スマホ**：GitHub Pages などに置いて開く（ES Modules を使っていないので `file://` でも動きます）
- ローカルサーバーで開く場合：`cd maou-keiei && python3 -m http.server 8000` → http://localhost:8000

| 操作 | タッチ | キーボード |
|---|---|---|
| レバー | 赤いレバー | Space / Enter / ↑ |
| 停止ボタン（左・中・右） | 3つの丸ボタン | Z X C / 1 2 3 / ← ↓ → |
| MAX BET / PUSH | 各ボタン | B / P |
| 開発者メニュー | 右上 DEV | D |
| 撮影モード（UIを隠す） | メニュー | H |
| 液晶のみ 16:9 表示 | メニュー | L |
| ミュート | メニュー | M |

音は最初にどこかをタップ（クリック）したあと鳴ります（ブラウザの仕様）。

## ゲーム性（仮仕様）

| 状態 | 内容 |
|---|---|
| **通常時「魔王城経営」** | 小役で資金（G）を稼ぐ → 10Gごとに決算（魔物の人件費を支払い）。黒字なら自動で**城を増築／魔物を雇用**。赤字なら魔物が辞めて勇者が近づく。スライム役で魔物が無料入社 |
| **CZ「勇者襲来」** | 勇者接近度100%、またはレア役で突入。**7G以内に勇者のHPを0に**すればAT。ダメージは役×**魔王軍の戦力（魔物の数・レベル・城Lv）**で決まるので、通常時の経営がそのまま効く。押し順正解で CRITICAL。最終Gに「魔王降臨」逆転あり |
| **AT「魔王経営RUSH」** | 1SET 20G。押し順ナビで純増。小役で**魔物が経験値を得てレベルアップ**、城が発展、レア役でG数上乗せ・魔物入社 |
| **継続ジャッジ** | SET終了ごとに「魔王軍 vs 勇者パーティー」の3G自動戦闘。**勝率＝育てた戦力 − 勇者パーティーの強さ**（SETごとに勇者も強くなる）。レア役で勝利確定 |
| **上位AT「世界征服RUSH」** | ジャッジ勝利時の昇格抽選（城Lv5・強チャンス目で優遇、5回撃退＋城Lv4以上で確定）や魔王7揃いで突入。人間の王国12地域を侵略。継続率約85%、負けても魔王経営RUSHへ戻る。全地域制圧で「世界征服達成」エンディング |

魔王7揃いは**リール逆回転フリーズ**のあと上位AT直撃。確率・枚数・バランスはすべて `js/config.js` で変えられます。

## 開発者用デモ機能（DEVボタン / Dキー）

- **モード呼び出し**：タイトル / 通常時 / CZ / CZ最終G / AT突入演出 / AT（即） / 継続ジャッジ / 上位AT昇格演出 / 上位AT（即） / エンディング
- **次ゲームの成立役を予約・固定**（例：強チャンス目、魔王7揃い）
- 城Lv・資金・勇者接近度・魔物の雇用・レベルを操作
- **オートプレイ**（押し順ナビどおりに自動で止める・速度 x1/x2/x4）、演出の倍速
- 状態表示（差枚・戦力・ジャッジ勝率）

### URLパラメータ（録画の段取り用）

| パラメータ | 効果 |
|---|---|
| `?rec=1` | 撮影モード（DEVボタン・カーソルを隠す） |
| `?view=lcd` | 液晶のみ 16:9 表示（右下に小さくリールを合成）→ 横長動画用 |
| `?auto=1` | オートプレイで起動 |
| `?mode=at` | 起動直後にそのモードへ（`title` `cz` `at` `judge` `upper` `ending` など） |
| `?mute=1` | 消音 |

例：`index.html?rec=1&mode=title` → タイトル画面から録画開始。
筐体全体は **9:16（720×1280 基準）** で、スマホの縦長録画にそのまま合います。

## ファイル構成（素材や演出を後から足しやすい分け方）

```
maou-keiei/
  index.html          筐体の骨組み
  css/cabinet.css     筐体デザイン・ランプ・ボタン
  js/core.js          共通処理（イージング・乱数・待機）
  js/config.js        ★仮スペック（確率・払い出し・経営バランス・リール配列）
  js/assets.js        ★外部素材の登録表（画像・音のパスを書くだけで差し替わる）
  js/audio.js         内蔵シンセ効果音・BGM
  js/fx.js            演出部品（パーティクル・魔法陣・放射光・稲妻・カットイン・文字の叩きつけ・画面振動）
  js/art.js           プログラム描画（魔物・勇者・魔王・城Lv1〜5・背景・図柄・ロゴ）
  js/reels.js         リール制御（最大4コマスベリ・押し順・出目判定）
  js/lcd.js           液晶エンジンと各モードのシーン
  js/seq.js           ★突入・昇格・終了などの演出シーケンス（ここに足すと新演出）
  js/game.js          ゲーム進行（抽選・経営・CZ・AT・ジャッジ・上位AT）
  js/cabinet.js       筐体の操作・7セグ・ランプ
  js/dev.js           開発者メニュー・オートプレイ
  docs/ASSETS.md      ★画像生成AI用の素材仕様書
```

### 画像素材の差し替え

1. `docs/ASSETS.md` の仕様で画像を作り、`assets/img/` に置く
2. `js/assets.js` の該当キーにパスを書く（例 `'monster.slime': 'assets/img/monster_slime.png'`）
3. 再読み込み。登録されていない素材はプログラム描画のまま動きます

効果音・BGMも同じく `sounds` にパスを書くと内蔵シンセから差し替わります。
