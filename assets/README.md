# 写真ライブラリ（V4〜）

機種・ホールの写真を、権利情報（metadata.json）と一緒に置く場所。台本で機種を指定すると自動で読み込まれる。
形式と「使える／使えない」の判定は `v3/photos.py` の先頭に書いてある。

- `machines/<機種キー>/` … front（正面）・detail（盤面アップ）・cabinet（筐体）・official（公式資料）
- `halls/<キー>/` … main（ホール風景）・real（実写）

写真が無い・許諾が未確認のときは、画面では「仮素材（実機写真ではありません）」と明記した図に置き換わり、
エピソードフォルダの `MISSING_PHOTOS.md` に不足一覧が出る。

※ 旧システム（反応集）の `generator/assets/machines/*.jpg` は出典・許諾の記録が無いので、このライブラリでは使わない。
