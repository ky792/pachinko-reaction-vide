あなたは動画自動生成システムを実装するエンジニアです。

目的：
YouTube向けの「パチンコ5ちゃん風反応集」を、台本から半自動で生成できる仕組みを作ってください。

今回の完成動画は8〜10分程度の横動画（16:9）を想定します。

既存動画：
pachisure_ep2_v7.mp4

この既存動画のデザイン・雰囲気をベースにしてください。
元動画は上書きせず、必ず別ファイルとして出力してください。

====================
■ 1. 動画の基本仕様

解像度：
1920x1080

FPS：
30fps

形式：
mp4 / H.264 / AAC

想定尺：
8〜10分

用途：
YouTube通常動画

動画ジャンル：
パチンコ・パチスロ系
掲示板反応集
作業中に垂れ流しできる動画

18. エンディング

====================
■ 3. 掲示板レスの表示

5ちゃん風のレスを画面に順番に表示してください。

基本ルール：

・1レスずつ読み上げる
・次のレスが来たら画面に追加する
・常時2〜4レス程度が見える状態
・古いレスは上方向へ流す
・重要レスだけ少し拡大
・短いレスは1〜2秒程度
・普通のレスは2〜4秒
・長いレスは4〜6秒程度

テンポは速すぎないようにしてください。

ショート動画ではなく、
「ラジオ感覚で流せる反応集」を目指します。

====================
■ 4. レスの見た目

既存動画のデザインを参考にしてください。

各レスには以下を表示：

名無しさん
レス番号
本文

例：

24：名無しさん
通常時あんだけ苦労して右入れたのに
3分後には通常画面おるの何なん

背景はパチンコ店をイメージしたもの。

レス本文はスマホでも読める大きさにしてください。

文字が小さくなりすぎないようにしてください。

====================
■ 5. 強調演出

以下のような短いレスは、
一瞬大きく表示してください。

例：

「草」

「わかる」

「それな」

「無理」

「地獄」

「正論やめろ」

「なんでだよ」

表示時に軽いSEを入れてください。

派手すぎる演出は不要です。

====================
■ 6. キャラクター

既存動画に登場する

・うさぎ
・ねこ

を動画内の案内キャラクターとして使用します。

キャラクター会話は
約1〜2分に1回程度入れてください。

例：

うさぎ：
やっと入ったRUSHが3分で終わると
何のために朝から打ってたのか分からなくなるよね。

ねこ：
でも20連した時は全部忘れるんよな。

うさぎ：
だからまた行くんだね。

ねこ：
やめろ。

キャラクター会話中は、
通常レスとは少し画面構成を変えてください。

====================
■ 7. 音声

VOICEVOX等を利用して、
各レスとキャラクター会話を音声化できる構造にしてください。

話者を分けられるようにしてください。

例：

掲示板レス：
VOICEVOX話者A

うさぎ：
VOICEVOX話者B

ねこ：
VOICEVOX話者C

設定はconfig.jsonなどから変更できるようにしてください。

読み上げ速度も設定可能にしてください。

初期設定：

掲示板レス：
1.15倍

うさぎ：
1.05倍

ねこ：
1.10倍

====================
■ 8. BGM

BGMを動画全体に薄く流してください。

音声が聞き取りやすいように、
BGM音量はかなり小さくしてください。

目安：

VOICE：100%

BGM：8〜15%

SE：20〜35%

最終動画の音量は、
YouTubeで極端に小さくならないよう調整してください。

目標：

約 -14〜-16 LUFS

====================
■ 9. SE

以下にSEを利用可能にしてください。

・レス表示
・強調レス
・章切り替え
・キャラクター登場
・オチ

ただし毎レスSEを入れる必要はありません。

うるさくならないようにしてください。

====================
■ 10. 章タイトル

章切り替え時に、

「その① 回らない」

「その② 図柄揃いが重い」

章タイトル表示時間：

約1〜1.5秒

■ 11. 冒頭

最初から長いタイトル画面を出さないでください。

0秒から強いレスを表示してください。

例：

名無しさん

名無しさん
回らない
当たらない
右に入らない
入っても続かない

名無しさん
それでも店に行く俺らが一番おかしい

名無しさん
正論やめろ

その後、約2〜3秒でタイトル表示。

タイトル：

最近のパチンコ、
さすがにキツすぎる件

パチンコ民の反応集

■ 13. 台本の管理方法

動画内容をコードに直接書かないでください。

script.json

または

script.yaml

から読み込める構造にしてください。

データ構造例：

{
"title": "最近のパチンコ、さすがにキツすぎる件",
"sections": [
{
"title": "その① 回らない",
"type": "reactions",
"items": [
{
"speaker": "名無しさん",
"text": "千円で12回とか普通になってるのヤバいだろ"
},
{
"speaker": "名無しさん",
"text": "12回ならまだ回ってる方やぞ"
}
]
},
{
"type": "character",
"items": [
{
"speaker": "うさぎ",
"text": "回らないと当たる当たらない以前に普通に退屈だよね。"
},
{
"speaker": "ねこ",
"text": "千円入れてデモ画面出た時の虚無よ。"
}
]
}
]
}

■ 15. 自動化

最終的には、

python generate.py scripts/episode_001.json

のようなコマンド1つで、

1. 台本読み込み
2. 音声生成
3. 音声尺取得
4. レス表示時間決定
5. キャラクター表示
6. BGM追加
7. SE追加
8. 字幕レンダリング
9. ffmpeg合成
10. mp4出力

まで実行できるようにしてください。

====================
■ 16. キャッシュ

VOICEVOXで生成した音声は
毎回生成し直さないでください。

本文からハッシュを生成して、
同じ文章の音声が存在する場合は
キャッシュを再利用してください。

====================
■ 17. 字幕生成

音声と字幕がズレないようにしてください。

音声ファイルの実際の長さを取得し、
その長さに合わせて字幕表示時間を決めてください。

固定秒数だけで処理しないでください。

■ 20. 実装時のルール

・既存ファイルを勝手に削除しない
・元動画を上書きしない
・APIキーをコードに直書きしない
・.envを使用する
・エラーが発生した場合は原因を表示する
・必要な依存関係はrequirements.txtへ書く
・README.mdに使い方を書く
・途中生成物はtempへ保存
・完成ファイルはoutputへ保存
