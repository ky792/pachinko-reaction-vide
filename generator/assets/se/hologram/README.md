# ホログラム用SE（ナギバク標準）

2026-11-27 にきょうじさんが聞き比べて決めたセット。ホログラム（解析モニター・データ表示など）が出るときは、明示的な指示がない限りこの音を使う。

| ファイル | 役割 | 鳴らすタイミング |
|---|---|---|
| `holo_charge.wav` | チャージ「ヒュイーン」 | 出現の約0.3秒前 |
| `holo_appear.wav` | 出現（B2：ガラスのベル・やや重め） | パネルが開く瞬間（映像と同時か2〜3フレーム早く） |
| `holo_data.wav` | データ表示「ピピッ」 | 数字・行が出ていくのに合わせて |
| `holo_disappear.wav` | 消える「シュッ」 | パネルが閉じ始める瞬間 |
| `holo_hum_loop_4s.wav` | 表示中のハム音（任意） | 表示中ずっとループ。音量はかなり小さく（BGMの下で聞こえるか聞こえないか） |

- 48kHz / 16bit / ステレオの WAV。
- 採用までの経緯：A（基本）/ B（上品）/ C（SF）の3案から B を選択 → B を重くした B2（やや重め）/ B3（かなり重め）から B2 を採用。
- 全部プログラムで合成した音（著作権フリー・クレジット不要）。作り直すときは `scripts/se/make_holo_se.py`（全案）と `scripts/se/make_heavy.py`（B2/B3）を使う。
