# まおうぐんの日々（試作版）

弱小魔王軍の魔王になって、魔物たちの暮らしを見守りながら育て・増やし・人間の村を侵略する 2D シミュレーション。
HTML / CSS / JavaScript だけで動きます（画像・音はすべてコードで生成。外部素材・API なし）。

## 遊び方
- `index.html` をブラウザで開くだけ（PC / スマホ対応）。ローカルサーバー不要。
  - 例: `python3 -m http.server` を `maou-game/` で実行して `http://localhost:8000/` を開いてもOK
- 目標：人間の村の **抵抗力を 0** にして支配する（通常速度で 10〜15 分ほど。1日 = 60 秒）

## 操作
| 操作 | PC | スマホ |
|---|---|---|
| 魔物の詳細 | クリック | タップ |
| 建設 | ボタン → 置きたい場所をクリック | ボタン → タップで位置決め → もう一度タップで確定 |
| 速度 | ⏸ ▶ ⏩ / Space・1・2 | ⏸ ▶ ⏩ |

## ルール（組み合わさって予想外のことが起きる）
- 魔物は自分で **食事・睡眠・農作業・訓練** を選ぶ。性格（勤勉 / 怠け者 / 好戦的 / 臆病 / 食いしん坊 / 陽気）で行動が変わる
- **ゴブリンは夜型**（夜に攻撃+30%、昼に昼寝）、**オークは昼型**（昼に攻撃+20%、夜に寝る）
- 同種族の成体2体 ＋ 収容数に空き ＋ 食料に余裕 → 子どもが生まれる。♥繁殖候補に指定すると優先的にペアに
- 子どもは親の能力（＋親が訓練で得た強さの一部）と性格を受け継ぐ。まれに **突然変異**（赤いゴブリン / 黒鉄のオーク、能力1.2倍、遺伝する）
- 食料が尽きると森の木の実を探しに行く。それも無く空腹が続くと、好戦的な魔物は喧嘩を始める
- 村に勝つと戦利品と抵抗力ダウン。ただし警戒度が上がり、守りが固くなって **夜襲** を受けるようになる
- 戦いで倒れた魔物は重傷か戦死。死んだ魔物は城の墓地に墓が建つ
- 臆病な魔物は戦闘中に逃げ出す（生き残るが戦力にならない）
- 資金が余ったら「魔物一覧」から流れ者を雇える（種族が絶えたときの立て直しにも）
