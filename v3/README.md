# ナギバク V3 解説動画システム

30秒Claude版の見た目（ネイビー×ゴールド×ホワイト、箱なし字幕、左上の番組タグ）をそのまま部品にし、
台本から自動でシーンを組み立てて MP4 にする仕組み。`lab/`・`reaction/`・`v3demo/` には手を入れていない。

```
python -m v3.build episodes/v3_hokuto --plan                       # シーン構成と必要素材 → PLAN.md
python -m v3.build episodes/v3_hokuto -o out/check.png --stills 3,9  # 静止画で確認
python -m v3.build episodes/v3_hokuto -o out/v3_hokuto.mp4           # 書き出し（1920x1080・30fps）
python -m v3.build episodes/v3_hokuto -o out/v3_hokuto.mp4 --final   # 本番：許諾 ok の素材だけ使う
```

## 制作の流れ

| 段階 | ファイル | 中身 |
| --- | --- | --- |
| 台本 | `episodes/<回>/script.txt` | `ナギ:` `バク:` `バク!:`（驚き）。必要なときだけ `@A`〜`@F`・`@host`・`@trans` |
| シーン構成の自動決定 | `v3/planner.py` | 行ごとにテンプレートを選び、続く行はまとめる。セリフの長さから時間を決める |
| 素材の読み込み | `v3/media.py` | `assets.json` で出典・許諾・AI生成かを管理。無い素材はラベル付きの仮素材 |
| レイアウト | `v3/templates.py` | A〜F の6テンプレート |
| モーション・キャラ | `v3/templates.py`, `v3/hosts.py` | ナレーションで語句を言う瞬間に合わせて表示。キャラは情報を避けて配置 |
| 字幕・音声・MP4 | `v3/build.py` | 名札つき字幕、BGM・効果音、`voices/<ID>.wav` があれば声も同期、ffmpeg |

## テンプレート

| | 用途 | 自動で選ばれる条件 | キャラの既定 |
| --- | --- | --- | --- |
| A | 実機・資料写真が主役の全画面 | 最初の行で「時代」「ホール」 | 出さない |
| B | 写真＋機種名＋スペック | 機種名＋「登場・導入」 | 話者を端に小さく（空いている角） |
| C | 年表・カレンダー | 「◯年」「◯月」 | 出さない |
| D | 大きな数字・比較 | %が2つ → 比較／`バク!:`で%が1つ → 大きな数字 | 基本出さない。バクの驚きだけ強調 |
| E | 要点を順に表示 | 「ポイント」「①」 | ナギを左下 |
| F | ナギバクの掛け合い | 数字を含まない会話 | 2人を大きく |

B は「年表で年を示す → 実機が入る → 左へ寄る → 機種名 → スペックを1行ずつ」の順に動く。
スペックは、ナレーションがその数字を言う瞬間に出る（`data.json` の `say`）。

## キャラの制御

- テンプレートごとの既定は `v3/hosts.py` の `DEFAULTS`。
- 台本で上書き：`@host nagi size=300 pos=bl alpha=0.9`、非表示は `@host baku off`。pos は bl・br・l・r・auto。
- テンプレートが「情報がある領域」を返し、キャラがその領域と8%以上重なる場合は表示しない（F と `@host` で指定したときを除く）。

## 素材と権利

`assets.json` の1件：`file`（エピソードフォルダからの相対パス）、`kind`（cutout=背景を抜いた実機、photo=全画面写真）、
`ai`（AI生成なら true、画面に「イメージ（AI生成）」と出る）、`license`（ok / pending / unknown）、`credit`（画面右下の出典）。

- 実機写真は背景透過PNGが一番きれい。白背景のJPGでも外周の白を自動で抜く。
- 写真が無い・許諾が ok でないときは、「仮素材｜実機写真に差し替え」の帯つきの概念イラストを出す（実物と誤認させない）。
- `--final` では許諾 ok 以外の素材を使わない。

## まだ無いもの

- 読み上げ音声の自動生成（AivisSpeech）。`voices/<ID>.wav` を置けば長さと音が自動で反映される。IDは `PLAN.md` の順番（001, 002…）。
- GitHub Actions のワークフロー。
- キャラの表情差分（今は各1枚）。

## ポップ演出（feat/v3-pop）

パチンコ好きがワクワクする方向に、ナギバク独自の演出を追加（既存機種の演出・音は使っていない）。

| 部品 | 中身 | 使う場面 |
| --- | --- | --- |
| `fx.hold_orb` | 保留変化風の玉：青→緑→赤→金（虹の縁、中央に研究所の「N」） | D 大きな数字の前の「溜め」 |
| `fx.gauge` | 期待度ゲージ風：10目盛りが青→金に満ちて「MAX」 | B 機種紹介の注目スペック |
| `fx.slam_text` / `burst` / `sparkles` | 数字を叩きつけて戻す＋集中線＋光の粒 | B・D の重要な数字 |
| `fx.ribbon` / `glint` | 「注目機種 ENTRY!」の帯、斜めの光 | B 人気機種の登場、見出し |
| `fx.flash` / `shake` | 白フラッシュ・画面振動（控えめ、要所だけ。字幕は揺らさない） | 数字の着地、機種登場 |
| `fx.emote` / `speed_lines` | 頭上の「！！」、右下からの集中線 | バクのツッコミ（`バク!:`） |
| `sfx.make` | キュイン（保留）、ドドン（数字）、ファンファーレ、びよん（ツッコミ）など10種を合成 | 各テンプレートの `events()` |

- 効果音・フラッシュ・振動のタイミングは各テンプレートの `events(sc)` に集約（映像と音が同じ時刻表で動く）
- BGM は 120BPM の明るいオリジナル。情報の場面はドラムあり、保留変化の間だけ止めて溜める
- キャラ：下から弾んで登場／呼吸の揺れ／ナギは話し始めに脳タンクが光る／バクのツッコミは跳ねて傾く。`バク!:` ならどの場面でも右下に飛び込む（F以外）
- 表情差分：`generator/assets/characters/v2/<who>/surprise.png`（驚き）、`nagi/explain.png`・`baku/talk.png`（話し中）を置くと自動で使う。無ければ normal.png ＋頭上の記号
